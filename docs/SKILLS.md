# 武功与内功配置

**创建日期**: 2026-04-22

---

## 武功等级说明

武功分为四个等级，等级越高威力越强，获取难度越大：

| 等级 | 名称 | 特点 | 弟子学习条件 |
|------|------|------|-------------|
| 初级 | 入门武功 | 基础效果，消耗较低 | 外门弟子可学 |
| 中级 | 进阶武功 | 较强效果，中等消耗 | 内门弟子可学 |
| 高级 | 秘传武功 | 强力效果，消耗较高 | 亲传弟子可学 |
| 顶级 | 镇派武功 | 最强效果，消耗最高 | 长老可学 |

---

## 门派说明

武功和内功可归属于特定门派，也可为江湖散人武功（无门派）：

| 门派 | 名称 | 特色 |
|------|------|------|
| BEGGAR | 丐帮 | 刚猛掌法、棒法 |
| SHAOLIN | 少林 | 内功深厚、护盾防御 |
| WUDANG | 武当 | 太极阴阳、攻防兼备 |
| EMEI | 峨眉 | 剑法精妙 |
| HUASHAN | 华山 | 剑法飘逸 |
| MINGJIAO | 魔教 | 内功恢复、反弹防御 |
| GUMU | 古墓派 | 剑法轻灵、双剑合璧 |
| TIANSHAN | 天山派 | 冰系武功、控制技能 |
| DALI | 大理段氏 | 指法绝学 |
