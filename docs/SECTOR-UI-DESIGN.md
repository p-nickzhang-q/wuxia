# 门派经营界面UI设计

> **注意**: 本文档描述 UI 布局，详细规则和公式请参考 `design/gdd/` 目录下的对应系统设计文档。

## 设计原则

1. **与战斗界面风格统一**：继承现有配色（金色、红色、蓝色、深色背景）
2. **信息层级清晰**：门派状态 → 设施区域 → 弟子列表 → 操作按钮
3. **响应式布局**：继承 `LayoutConstants` 的缩放机制
4. **以系统设计为准**：UI 操作必须与 `design/gdd/` 中的系统规则一致

### 1.3 弟子卡片显示说明

根据 `disciple-task-priority-system.md`，弟子卡片应显示：

| 信息 | 格式 | 说明 |
|------|------|------|
| 弟子名称 | "弟子A" | 弟子姓名 |

**交互方式**：弟子事务由权重系统自动执行，玩家点击弟子卡片进入详情界面配置权重策略。

```

| 信息 | 格式 | 说明 |

| 月 | "三月" | 12个月循环：正月、二月、三月...腊月 |

**时间流逝规则**：
- 门派主界面：时间自动流逝，20秒=1时辰
- 其他界面（弟子详情、设施建设、江湖任务等）：时间暂停
- 点击弟子/设施卡片查看：时间暂停
- 事件触发弹出对话框：时间暂停
- 点击暂停按钮：手动暂停时间

**暂停按钮**：
- 位置：状态栏右侧
- 图标：⏸（暂停符号）
- 状态：暂停时显示▶（播放符号），可点击恢复

### 2.3 权重配置规则

根据 `disciple-task-priority-system.md`：

- **权重 = 精力分配比例**：权重5表示消耗50%精力
- **总和必须为10**：意味着100%精力被规划
- **高权重优先执行**：按权重从高到低执行事务
- **权重为0即禁止**：该事务不会被分配精力
- **修改立即生效**：调整权重后，下次精力分配使用新权重

### 2.5 目标选择下拉框详情

**修炼武功下拉框**（显示武功完整信息）：

下拉选项格式：
```
降龙十八掌 (Lv.1 空手) - 精力12, 2时辰
  招式: 降龙十八掌·亢龙有悔 (攻击伤害+50%)
├── 基础拳法 (Lv.1 空手) - 精力10, 2时辰
├── 基础掌法 (Lv.1 空手) - 精力10, 2时辰
└── (槽位已满, 无法学习更多武功)
```

- 武功名称 + 等级 + 类型
- 精力消耗 + 学习时长
- 主要招式效果预览
- 武功槽位已满时显示警告
- 无藏经阁时显示"(需建设藏经阁)"

├── 打狗棒法 - 经验20% 效果64% → 训练后经验29%
└── (无已学武功)
```

- 武功名称
- 当前经验值 + 当前效果
- 训练后预计经验值增量
- 无已学武功时显示警告

## 十四、弟子事务自动化说明

弟子事务由**权重系统自动执行**，玩家交互流程为：

1. **配置阶段**：点击弟子卡片 → 进入详情界面 → 直接在界面上配置权重策略
2. **执行阶段**：弟子自动按权重分配精力执行事务（修炼→训练→探索→休息等）
3. **干预阶段**：需要调整时，再次点击弟子修改权重配置
4. **江湖任务阶段**：点击主界面"江湖任务"按钮 → 选择任务 → 选择弟子 → 执行任务
5. **出战阶段**：点击主界面"出战"按钮 → 选择弟子 → 进入战斗场景

**核心交互点**：
- 弟子卡片点击 → 详情界面（含权重配置）
- 预设模板一键应用 → 快速配置权重
- 弟子卡片显示当前事务 → 实时监控执行状态
- 主界面"江湖任务"按钮 → 进入任务界面，手动选择任务和弟子

**两种执行方式对比**：

| 执行方式 | 事务类型 | 操作流程 |
|---------|---------|---------|
| 自动执行（权重系统） | 修炼、训练、探索、炼丹、锻造、休息 | 设置权重 → 弟子自动执行 |
| 手动执行 | 江湖任务 | 点击按钮 → 选择任务 → 选择弟子 → 执行 |
