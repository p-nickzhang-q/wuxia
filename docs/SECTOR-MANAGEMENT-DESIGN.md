# 门派经营概念框架

## 概述

本游戏结合 **门派经营 + 卡牌战斗**，玩家扮演一个新兴门派的掌门人，通过招募弟子、修炼武功、建设门派、与其他门派互动，最终成为武林盟主。

---

## 一、核心循环

```
回合循环:
┌─────────────────────────────────────────────┐
│  1. 门派经营阶段（主界面）                    │
│     - 查看弟子状态                            │
│     - 分配修炼任务                            │
│     - 建设门派设施                            │
│     - 外交决策                                │
│                                              │
│  2. 事件阶段                                  │
│     - 触发随机事件（江湖传闻、弟子冲突等）    │
│     - 做出决策影响门派发展                    │
│                                              │
│  3. 战斗阶段（可选）                          │
│     - 挑战其他门派                            │
│     - 应对入侵                                │
│     - 江湖任务                                │
│     → 进入卡牌战斗系统                        │
│                                              │
│  4. 结算阶段                                  │
│     - 资源收入                                │
│     - 弟子成长                                │
│     - 声望变化                                │
└─────────────────────────────────────────────┘
```

## 二、门派属性系统

### 2.1 门派基础属性

| 属性 | 说明 | 影响 |
|------|------|------|
| **声望** | 门派在江湖中的名望 | 解锁高级弟子招募、其他门派态度 |
| **财富** | 金钱资源 | 建设设施、购买物资、招募弟子 |
| **武学底蕴** | 门派武功传承深度 | 弟子修炼效率、可传授武功上限 |
| **势力范围** | 门派影响力区域 | 资源收入、事件触发概率 |

### 2.2 门派资源

| 资源 | 说明 | 来源 |
|------|------|------|
| **银两** | 基础货币 | 势力范围收入、任务奖励、交易 |
| **药材** | 弟子疗伤恢复 | 采集、购买、事件 |
| **秘籍** | 武功秘籍 | 探索、购买、击败门派获得 |
| **人才** | 可招募的弟子池 | 声望吸引、主动寻找 |

## 三、弟子系统

### 3.1 弟子属性

每位弟子继承现有战斗系统属性，增加经营层属性：

| 属性 | 说明 |
|------|------|
| **体力/内力/轻功** | 战斗属性（现有系统） |
| **武功列表** | 已学会的武功（现有系统） |
| **卡组** | 战斗卡组配置（现有系统） |
| **忠诚度** | 对门派的忠诚，过低可能叛逃 |
| **资质** | 学习武功效率 |
| **心境** | 影响修炼速度和战斗表现 |
| **状态** | 健康/受伤/修炼中/任务中 |

### 3.2 弟子培养

```
培养路径:
┌────────────────────────────────────┐
│  弟子 → 选择修炼武功 →             │
│    ├─ 自修（低效，无需掌门时间）   │
│    ├─ 掌门传授（高效，消耗掌门时间）│
│    └─ 奇遇/任务（获得秘籍）        │
│                                    │
│  修炼进度 → 每回合积累 →           │
│    ├─ 完成修炼 → 学会武功招式      │
│    ├─ 继续修炼 → 提升武功等级      │
│    └─ 遇到瓶颈 → 需要特殊条件突破  │
└────────────────────────────────────┘
```

### 3.3 弟子招募

- **声望吸引**: 高声望自动有弟子慕名而来
- **主动招募**: 消耗资源外出寻找
- **特殊人才**: 完成任务/事件获得独特弟子
- **俘虏转化**: 战败门派弟子可收编（忠诚度低）

## 四、门派建设系统

### 4.1 设施类型

| 设施 | 功能 | 建设成本 |
|------|------|----------|
| **练武场** | 弟子自修效率提升 | 低 |
| **藏书阁** | 存放秘籍，修炼时有加成 | 中 |
| **丹药房** | 生产药材，治疗弟子 | 中 |
| **演武台** | 弟子切磋，提升实战经验 | 中 |
| **聚贤厅** | 提升声望吸引效率 | 高 |
| **闭关室** | 高级修炼场所，突破瓶颈 | 高 |
| **暗室** | 特殊功能（情报、特殊任务） | 高 |

### 4.2 设施升级

每类设施可升级，提升效率和容量：
- 练武场 Lv1 → Lv2 → Lv3（容纳弟子数增加，效率提升）
- 藏书阁 Lv1 → Lv2 → Lv3（秘籍容量增加，加成提升）

## 五、武功传承系统

### 5.1 武功获取

| 来源 | 说明 |
|------|------|
| **门派基础武功** | 开局自带（如玩家选择丐帮，自带降龙掌） |
| **秘籍学习** | 获得秘籍后可传授弟子 |
| **奇遇获得** | 事件/任务中获得独特武功 |
| **击败门派** | 战胜其他门派可能获得其武功 |

### 5.2 武功传授限制

- 掌门传授武功需要消耗"掌门时间"
- 每回合掌门时间有限，需权衡分配
- 高级武功需要弟子资质达到要求
- 某些武功有门派限制（如丐帮武功只传丐帮弟子）

## 六、门派互动系统

### 6.1 其他门派状态

| 关系 | 说明 | 影响 |
|------|------|------|
| **友好** | 可能交换秘籍、互助 | 可请求援助 |
| **中立** | 无特殊互动 | 维持现状 |
| **敌对** | 可能主动攻击 | 需防备 |
| **臣服** | 战败后臣服于你 | 定期上贡，可调用弟子 |

### 6.2 互动选项

- **外交**: 送礼改善关系、结盟
- **挑衅**: 降低关系，可能引发战斗
- **交易**: 交换秘籍、弟子、资源
- **挑战**: 直接发起门派战
- **情报**: 了解对方弟子配置、武功

### 6.3 门派战

```
门派战流程:
┌─────────────────────────────────┐
│  1. 选择出战弟子（最多N名）     │
│  2. 对方选择应战弟子            │
│  3. 依次进行单挑战斗            │
│     → 进入卡牌战斗系统          │
│  4. 胜负判定                    │
│     ├─ 胜利: 获得声望、可能获得 │
│     │        秘籍/弟子/臣服     │
│     ├─ 失败: 损失声望、弟子受伤 │
│     │        可能被迫臣服       │
└─────────────────────────────────┘
```

## 七、事件系统

### 7.1 事件类型

| 类型 | 示例 |
|------|------|
| **江湖传闻** | 听说某处有秘籍出现 |
| **弟子事件** | 弟子间产生矛盾 |
| **外部威胁** | 其他门派挑衅、山贼入侵 |
| **奇遇** | 获得独特武功/弟子 |
| **抉择** | 需做出道德/利益选择 |

### 7.2 事件影响

- 选择不同结果影响声望、弟子忠诚、资源
- 好的决策可能带来长期收益
- 错误决策可能导致弟子叛逃、门派衰落

---

## 八、胜利条件

### 8.1 主目标

**成为武林盟主** - 声望达到顶级，并击败/臣服所有主要门派

### 8.2 可选目标

- **武林至尊**: 所有弟子学会顶级武功
- **一统江湖**: 所有门派臣服
- **传承万代**: 建设满级门派设施

## 九、与卡牌战斗系统的整合

### 9.1 整合方式

```
经营层 → 战斗层:
┌────────────────────────────────────┐
│  选择出战弟子 →                    │
│    - 弟子的HP/MP/轻功 → 战斗初始值 │
│    - 弟子的武功 → 战斗可用武功     │
│    - 弟子的卡组 → 战斗卡组         │
│                                    │
│  进入卡牌战斗 →                    │
│    - 使用现有战斗系统              │
│    - 战斗结果 → 影响经营层         │
│                                    │
│  战斗结果 → 经营层影响:            │
│    - 弟子受伤 → 需要治疗/修养      │
│    - 弟子成长 → 经验提升           │
│    - 门派声望 → 根据胜负变化       │
└────────────────────────────────────┘
```

### 9.2 战斗层对经营层的反馈

| 战斗结果 | 经营层影响 |
|----------|------------|
| **胜利** | 弟子获得实战经验，可能领悟武功 |
| **失败** | 弟子受伤需治疗，忠诚度可能下降 |
| **重伤** | 弟子需要长时间修养，消耗药材 |
| **领悟** | 战斗中可能领悟武功招式 |

## 十、简化版原型建议

### 10.1 第一版可省略

- 复杂设施系统（只保留基础练武场）
- 弟子心境系统
- 详细的事件系统
- 多弟子同时出战（改为单挑）

### 10.2 第一版核心

- 门派基础属性（声望、财富）
- 弟子招募（声望吸引）
- 弟子修炼（学会武功）
- 门派挑战（单挑战斗）
- 简单胜利条件（击败3个门派）

## 附录：门派预设

### 可选门派（玩家开局）

| 门派 | 特色 | 开局武功 |
|------|------|----------|
| **丐帮** | 高声望起点，降龙掌强势 | 降龙十八掌、打狗棒法 |
| **武当** | 内功深厚，擅长防守 | 太极拳、太极剑 |
| **华山** | 剑法犀利，轻功优秀 | 独孤九剑（需修炼） |
| **明教** | 弟子众多，内功恢复强 | 九阳神功、乾坤大挪移 |
| **古墓派** | 轻功顶级，弟子稀缺 | 玉女剑法、玉女心经 |

### 对手门派（AI控制）

可使用现有24个角色所属门派，每个门派配置：
- 门派属性（声望、弟子配置）
- 门派武功（门派弟子共性武功）
- 门派行为倾向（友好/中立/敌对）
