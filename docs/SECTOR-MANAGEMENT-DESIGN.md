# 门派经营概念框架

> **注意**: 本文档是各系统设计的汇总框架。详细的规则和公式请参考 `design/gdd/` 目录下的对应系统设计文档。

## 概述

本游戏结合 **门派经营 + 卡牌战斗**，玩家扮演一个新兴门派的掌门人，通过建设设施、招募弟子、修炼武功、探索江湖，最终成为武林盟主。

---

## 一、核心循环

```
游戏流程:
┌─────────────────────────────────────────────┐
│  1. 门派经营阶段（主界面）                    │
│     - 建设门派设施                            │
│     - 招募弟子                                │
│     - 安排弟子修炼武功                        │
│                                              │
│  2. 探索阶段                                  │
│     - 派遣弟子探索江湖城市                    │
│     - 获取资源（木材、金属、药材）            │
│     - 触发江湖事件                            │
│                                              │
│  3. 战斗阶段                                  │
│     - 门派挑战（主动发起）                    │
│     - 门派战争事件（被动触发）                │
│     → 进入卡牌战斗系统                        │
└─────────────────────────────────────────────┘
```

## 三、门派设施

详见 `design/gdd/facility-system.md`

### 可建设设施

| 设施 | 功能 | 基础成本 | 最高等级 |
|------|------|----------|----------|
| **徒手练武场** | 空手类武功训练效率+20%/级 | 200银两 | 5 |
| **兵器练武场** | 兵器类武功训练效率+20%/级 | 200银两 | 5 |
| **藏经阁** | 学习新武功，解锁高级武功 | 300银两 | 5 |
| **炼丹房** | 炼制药品 | 150银两 | 5 |
| **兵器坊** | 制作装备 | 150银两 | 5 |
| **议事厅** | 接受江湖任务 | 250银两 | 5 |
| **弟子房** | 弟子上限+1，精力恢复效率提升 | 100银两 | 5 |

### 弟子房与精力恢复

- 每个弟子房容纳 **1名弟子**
- 弟子房等级影响精力恢复效率：
  - Lv.1: 50%
  - Lv.2: 60%
  - Lv.3: 70%
  - Lv.4: 80%
  - Lv.5: 90%

## 四、门派势力

详见 `design/gdd/faction-power-system.md`

### 可选门派

玩家开局可选择以下门派之一：

| 门派 | 分类 | 分配城市 |
|------|------|----------|
| 少林 | 正派 | 洛阳 |
| 丐帮 | 正派 | 开封 |
| 大理段氏 | 正派 | 大理 |
| 天山派 | 正派 | 敦煌 |
| 华山 | 正派 | 长安 |
| 武当 | 正派 | 燕京 |
| 桃花岛 | 正派 | 杭州 |
| 古墓派 | 正派 | 苏州 |
| 侠客岛 | 正派 | 无大陆城市 |
| 青城派 | 正派 | 成都 |
| 魔教 | 邪派 | 襄阳 |

### 门派关系值

- 关系值范围：**-100 到 100**
- 关系等级：
  - **极友好** (90-100): 探索精力-20%，任务奖励+20%
  - **友好** (50-89): 仇杀概率-10%，寻宝概率+5%，任务奖励+10%
  - **中立** (-49-49): 无特殊影响
  - **敌对** (-50--89): 仇杀概率+20%，寻宝概率-5%，任务奖励-10%
  - **极敌对** (-90--100): 仇杀概率+30%，可能触发门派战争

### 主城机制

- 选择门派后，该门派的城市成为玩家主城
- 主城探索消耗精力减少50%
- 主城探索时间减少50%

## 五、弟子培养

### 精力系统

详见 `design/gdd/vitality-system.md`

- 精力上限 = 基础精力(50) + 根骨×5 + 定力×3
- 精力消耗：
  - 制作装备：10 + 装备等级×5
  - 制作药品：5 + 药品等级×3
  - 武功训练：15
  - 江湖任务：20
- 精力恢复：
  - 睡觉（有房间）：上限×恢复效率（弟子房等级决定）
  - 睡觉（无房间）：上限×20%
  - 自然恢复：上限×5%/小时

### 武功学习

详见 `design/gdd/martial-arts-learning-system.md`

**学习新武功**：
- 场所：藏经阁
- 藏经阁等级决定可解锁武功级别
- 弟子境界决定武功槽位上限：
  - 外门：1个
  - 内门：2个
  - 亲传：3个
  - 长老/掌门：4个

**训练已学武功**：
- 场所：练武场（空手类→徒手练武场，兵器类→兵器练武场）
- 每次训练消耗15精力
- 经验值增量 = 5% × 悟性系数 × 练武场效率系数

**武功效果**：
- 效果倍率 = 50% + 经验值×70%
- 0%经验：50%效果（刚学会）
- 100%经验：120%效果（精通）

## 六、江湖探索

详见 `design/gdd/jianghu-map-system.md` 和 `jianghu-event-system.md`

### 探索流程

1. 选择弟子和目标城市
2. 消耗精力开始探索
3. 获取资源（木材、金属、药材）
4. 30%概率触发江湖事件

### 江湖事件类型

| 事件类型 | 基础概率 | 奖励/惩罚 |
|---------|----------|-----------|
| **仇杀事件** | 25% | 胜利：装备/药品+功绩15；失败：损失HP |
| **寻宝事件** | 30% | 银两30-100、声望10-30、秘籍碎片1-3 |
| **比武事件** | 25% | 胜利：声望20+功绩10；失败：声望-5 |
| **招募事件** | 20% | 消耗100-300银两招募弟子 |

### 门派关系对事件的影响

- 友好城市：仇杀概率-10%，寻宝概率+5%
- 敌对城市：仇杀概率+20%，寻宝概率-5%

### 门派战争事件

- 触发条件：与某门派关系≤-90，探索该门派城市
- 触发概率：10%
- 立场选择：支持友好门派、支持敌对门派、中立旁观
- 关系变化：±30

## 七、门派挑战（主动战斗）

玩家可主动发起门派挑战，与目标门派弟子进行战斗。

**战斗流程**（简化版）：
1. 选择目标门派
2. 选择出战弟子
3. 进入卡牌战斗系统
4. 战后结算：声望变化、弟子受伤/成长

> **注意**: 门派挑战的详细规则待补充。当前优先实现江湖事件中的战斗。

## 八、与卡牌战斗系统的整合

详见 `design/gdd/game-design.md`

```
经营层 → 战斗层:
┌────────────────────────────────────┐
│  弟子的属性 → 战斗初始值           │
│    - HP/MP/轻功 → 直接继承        │
│    - 已学武功 → 战斗可用武功       │
│    - 武功经验值 → 武功效果倍率     │
│                                    │
│  进入卡牌战斗 →                    │
│    - 使用现有战斗系统              │
│    - 战斗结果 → 影响经营层         │
│                                    │
│  战斗结果 → 经营层影响:            │
│    - 弟子受伤 → 需要药品治疗       │
│    - 弟子消耗精力 → 需要休息       │
│    - 门派声望 → 根据胜负变化       │
└────────────────────────────────────┘
```

- 设施升级的完整动画
