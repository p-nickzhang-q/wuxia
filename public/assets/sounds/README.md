## 获取音效资源

推荐免费音效网站：
- [Freesound](https://freesound.org/) - 免费音效库
- [Pixabay](https://pixabay.com/sound-effects/) - 免版税音效
- [Mixkit](https://mixkit.co/free-sound-effects/) - 免费音效

## 注意事项

- 音效文件格式建议使用 MP3（兼容性好）
- 音效时长建议控制在 1-3 秒
- BGM 需要可以循环播放
- 文件大小尽量控制在 1MB 以内
