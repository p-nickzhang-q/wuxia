# 门派势力系统 (Faction Power System)

> **Status**: Approved
> **Author**: User + Claude
> **Last Updated**: 2026-05-06
> **Implements Pillar**: 江湖世界

## Overview

门派势力系统管理玩家门派与NPC门派之间的关系和势力分布。玩家在游戏开始时从10个门派中选择一个作为自己的门派并扮演掌门，该门派的城市成为玩家的主城。门派分为正派（丐帮、大理段氏、天山派、华山、武当、桃花岛、古墓派、侠客岛、青城派）和邪派（魔教），正派之间默认友好关系，正派-邪派默认敌对关系。玩家通过探索、事件、任务等行为改变与各门派的关系值，关系值影响探索城市的事件触发概率和任务奖励。该系统为江湖世界增加势力格局感，让探索不同城市有不同风险和收益。

## Player Fantasy

门派势力系统让玩家感受到"江湖掌门"的代入感——作为门派掌门，感受江湖正邪对立的世界格局，决定与哪些门派交好，与哪些门派对抗。正派玩家探索邪派城市（魔教-襄阳）有"深入敌境"的风险和刺激感，邪派玩家探索正派城市有"挑战权威"的叛逆感。自己门派的城市是"家"，探索友好门派城市有"盟友相助"的安全感。关系值的变化让玩家有"势力博弈"的策略感——帮助友好门派会加深关系，攻击敌对门派会激化矛盾。门派战争事件让玩家有"江湖风云"的史诗感——正邪大战，选择立场影响江湖格局。

## Detailed Design

### Core Rules

**门派列表与分类**：

玩家可选择的11个门派（少林新增，侠客岛保留但不分配大陆城市）：

| 门派 | 分类 | 分配城市 |
|------|------|----------|
| 少林 | 正派 | 洛阳 |
| 丐帮 | 正派 | 开封 |
| 大理段氏 | 正派 | 大理 |
| 天山派 | 正派 | 敦煌 |
| 华山 | 正派 | 长安 |
| 武当 | 正派 | 燕京 |
| 桃花岛 | 正派 | 杭州 |
| 古墓派 | 正派 | 苏州 |
| 侠客岛 | 正派 | 无大陆城市（岛屿门派） |
| 青城派 | 正派 | 成都 |
| 魔教 | 邪派 | 襄阳 |

正派：10个（少林、丐帮、大理段氏、天山派、华山、武当、桃花岛、古墓派、侠客岛、青城派）
邪派：1个（魔教）

**门派关系值系统**：

关系值范围：-100 到 100
- -100：极敌对
- -50：敌对阈值
- 0：中立
- 50：友好阈值
- 100：极友好

关系等级划分：
- 友好：关系值 ≥ 50
- 中立：关系值 -50 ~ 50
- 敌对：关系值 ≤ -50

**初始关系值**：

玩家选择门派后：
- 玩家与自己的门派：初始关系值 = 100（极友好）
- 正派玩家与正派门派：初始关系值 = 50（友好）
- 正派玩家与邪派（魔教）：初始关系值 = -50（敌对）
- 魔教玩家与正派门派：初始关系值 = -50（敌对）
- 魔教玩家与自己（魔教）：初始关系值 = 100（极友好）

**关系值变化触发条件**：

| 行为 | 关系值变化 | 说明 |
|------|-----------|------|
| 探索友好门派城市 | +5 | 加深与该门派的友好关系 |
| 完成友好门派任务 | +20 | 大幅提升友好关系 |
| 攻击门派弟子（仇杀事件胜利） | -15 | 激化与该门派的敌对关系 |
| 门派战争事件参与 | ±30 | 根据立场大幅改变关系 |

**关系值对探索的影响**：

| 关系等级 | 探索影响 |
|---------|---------|
| 友好 | 仇杀事件概率-10%，寻宝事件概率+5%，任务奖励+10% |
| 中立 | 无特殊影响 |
| 敌对 | 仇杀事件概率+20%，寻宝事件概率-5%，任务奖励-10% |

**玩家主城规则**：

- 玩家选择门派后，该门派分配的城市成为玩家主城
- 主城探索消耗精力减少50%（-10精力）
- 主城探索时间减少50%
- 主城无法被其他玩家门派控制
- 主城事件触发概率固定30%（不受关系影响）

### States and Transitions

**门派关系状态**：

| 状态 | 关系值范围 | 影响 |
|------|-----------|------|
| 极友好 | 90-100 | 探索友好门派城市消耗精力-20%，任务奖励+20% |
| 友好 | 50-89 | 仇杀事件概率-10%，寻宝事件概率+5%，任务奖励+10% |
| 中立 | -49-49 | 无特殊影响 |
| 敌对 | -50--89 | 仇杀事件概率+20%，寻宝事件概率-5%，任务奖励-10% |
| 极敌对 | -90--100 | 仇杀事件概率+30%，寻宝事件概率-10%，任务奖励-20%，可能触发门派战争 |

状态转换：
- 极友好 → 友好 → 中立 → 敌对 → 极敌对：通过攻击门派弟子、探索敌对城市等行为降低关系
- 极敌对 → 敌对 → 中立 → 友好 → 极友好：通过完成任务、探索友好城市等行为提升关系

### Interactions with Other Systems

| 系统 | 方向 | 数据流 | 接口 |
|------|------|--------|------|
| 江湖地图系统 | 关联者 | 城市门派归属 | `getCityFaction(cityId): Faction`（城市门派归属）<br>`getPlayerFaction(): Faction`（玩家门派） |

## Formulas

### 关系值变化公式

```
关系值变化量 = 基础变化量

探索友好门派城市：关系值 +5
完成友好门派任务：关系值 +20
攻击门派弟子（仇杀事件胜利）：关系值 -15
门派战争事件参与：关系值 ±30
```

### 关系值限制公式

```
关系值上限 = 100
关系值下限 = -100

变化后关系值 = clamp(当前关系值 + 变化量, -100, 100)
```

**示例计算**：

| 当前关系值 | 变化行为 | 变化量 | 结果关系值 |
|-----------|---------|--------|-----------|
| 50 | 探索友好城市 | +5 | min(55, 100) = 55 |
| 45 | 完成任务 | +20 | min(65, 100) = 65 |
| -40 | 攻击弟子 | -15 | max(-55, -100) = -55 |
| 95 | 探索友好城市 | +5 | min(100, 100) = 100（已到上限） |

### 事件概率修正公式

```
仇杀事件概率修正 = 基础概率 + 关系等级修正

基础概率 = 25%
关系等级修正：
  极友好（90-100）：-15%
  友好（50-89）：-10%
  中立（-49-49）：0%
  敌对（-50--89）：+20%
  极敌对（-90--100）：+30%
```

**示例计算**：

| 门派关系等级 | 基础概率 | 关系等级修正 | 仇杀事件概率 |
|-------------|---------|-------------|-------------|
| 极友好（100） | 25% | -15% | 25% - 15% = 10% |
| 友好（60） | 25% | -10% | 25% - 10% = 15% |
| 中立（0） | 25% | 0% | 25% + 0% = 25% |
| 敌对（-60） | 25% | +20% | 25% + 20% = 45% |
| 极敌对（-95） | 25% | +30% | 25% + 30% = 55% |

### 任务奖励修正公式

```
任务奖励修正 = 基础奖励 × 关系等级倍数

关系等级倍数：
  极友好（90-100）：1.2（+20%）
  友好（50-89）：1.1（+10%）
  中立（-49-49）：1.0（无修正）
  敌对（-50--89）：0.9（-10%）
  极敌对（-90--100）：0.8（-20%）
```

**示例计算**：

| 门派关系等级 | 基础奖励 | 关系等级倍数 | 实际奖励 |
|-------------|---------|-------------|---------|
| 极友好（100） | 银两50 | 1.2 | 50 × 1.2 = 60 |
| 友好（60） | 银两50 | 1.1 | 50 × 1.1 = 55 |
| 中立（0） | 银两50 | 1.0 | 50 × 1.0 = 50 |
| 敌对（-60） | 银两50 | 0.9 | 50 × 0.9 = 45 |
| 极敌对（-95） | 银两50 | 0.8 | 50 × 0.8 = 40 |

### 主城探索消耗公式

```
主城探索精力消耗 = 基础消耗 × 0.5 = 20 × 0.5 = 10
主城探索时间消耗 = 基础时间 × 0.5

基础消耗 = 20精力
基础时间 = 2小时 + 距离 × 1小时
```

**示例计算**：

玩家选择少林，洛阳成为主城：
- 洛阳距离门派 = 1（假设）
- 常规探索时间 = 2 + 1 × 1 = 3小时
- 主城探索时间 = 3 × 0.5 = 1.5小时
- 常规探索精力 = 20
- 主城探索精力 = 20 × 0.5 = 10

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 关系值超过上限100 | 限制为100，不继续增加 |
| 关系值低于下限-100 | 限制为-100，不继续减少 |
| 玩家未选择门派（初始状态） | 所有关系值默认0（中立），等待玩家选择门派后初始化 |
| 玩家选择门派后重复选择 | 拒绝操作，提示"已选择门派，无法更改" |
| 门派战争事件触发时关系值已达极敌对 | 直接触发门派战争，关系值不再变化 |
| 探索中立门派城市时关系变化 | 关系值变化正常执行（+5或-15），不受中立状态限制 |
| 攻击自己门派的弟子 | 拒绝操作，提示"无法攻击自己门派的弟子" |
| 完成自己门派的任务 | 任务奖励+30%（主城加成+友好加成叠加） |
| 探索无门派归属的城市 | 关系值不变化，事件概率无修正 |
| 存档恢复时关系值超出范围 | 限制在-100~100范围内，记录警告 |
| 存档恢复时门派不匹配 | 恢复为默认门派选择状态，提示玩家重新选择 |
| 侠客岛（无大陆城市）被选为主城 | 侠客岛玩家无大陆主城，探索所有城市消耗正常精力 |
| 魔教玩家探索正派城市 | 所有正派城市初始敌对，仇杀事件概率+20% |
| 正派玩家探索魔教城市 | 魔教城市初始敌对，仇杀事件概率+20% |
| 关系值变化后跨越关系等级 | 立即更新关系等级，UI显示新等级 |
| 门派战争事件对中立门派的影响 | 中立门派关系值不受战争影响，除非玩家选择参与 |

## Tuning Knobs

| Knob | 默认值 | 安全范围 | 影响什么 | 极端设置后果 |
|------|--------|----------|----------|-------------|
| 关系值上限 | 100 | 50-200 | 极友好最大值 | 太低：无法达到极友好<br>太高：关系值积累过长 |
| 关系值下限 | -100 | -50--200 | 极敌对最小值 | 太低：无法达到极敌对<br>太高：敌对积累过快 |
| 友好阈值 | 50 | 30-80 | 友好关系等级起点 | 太低：友好范围过大<br>太高：友好范围过小 |
| 敌对阈值 | -50 | -30--80 | 敌对关系等级起点 | 太低：敌对范围过大<br>太高：敌对范围过小 |
| 探索友好城市关系变化 | +5 | +2-+15 | 探索友好城市加成 | 太低：探索对关系影响小<br>太高：关系积累过快 |
| 完成任务关系变化 | +20 | +10-+50 | 任务对关系的贡献 | 太低：任务动力不足<br>太高：关系积累过快 |
| 攻击弟子关系变化 | -15 | -5--30 | 战斗对关系的影响 | 太低：战斗风险不足<br>太高：关系恶化过快 |
| 门派战争关系变化 | ±30 | ±15-±50 | 战争对关系的重大影响 | 太低：战争意义不足<br>太高：关系剧烈变化 |
| 极友好仇杀概率修正 | -15% | -5%--25% | 极友好城市探索安全度 | 太低：极友好无优势<br>太高：极友好过于安全 |
| 友好仇杀概率修正 | -10% | -5%--20% | 友好城市探索安全度 | 同上 |
| 敌对仇杀概率修正 | +20% | +10%-+30% | 敌对城市探索风险 | 太低：敌对风险不足<br>太高：敌对过于危险 |
| 极敌对仇杀概率修正 | +30% | +20%-+50% | 极敌对城市探索风险 | 同上 |
| 极友好任务奖励倍数 | 1.2 | 1.1-1.5 | 极友好任务奖励 | 太低：极友好无优势<br>太高：奖励过多 |
| 友好任务奖励倍数 | 1.1 | 1.05-1.2 | 友好任务奖励 | 同上 |
| 敌对任务奖励倍数 | 0.9 | 0.7-0.95 | 敌对任务惩罚 | 太低：任务无意义<br>太高：惩罚不足 |
| 极敌对任务奖励倍数 | 0.8 | 0.5-0.9 | 极敌对任务惩罚 | 同上 |
| 主城探索精力折扣 | 50% | 30%-70% | 主城探索便利度 | 太低：主城优势不足<br>太高：主城过于便利 |
| 主城探索时间折扣 | 50% | 30%-70% | 主城探索速度 | 同上 |
| 正派玩家与正派初始关系 | 50 | 30-70 | 正派阵营初始友好度 | 太低：正派无阵营感<br>太高：初始过于友好 |
| 正派玩家与邪派初始关系 | -50 | -30--70 | 正邪阵营初始敌对度 | 太低：正邪对立不足<br>太高：初始过于敌对 |
| 可选门派数量 | 11 | 5-15 | 玩家门派选择范围 | 太少：选择有限<br>太多：复杂度过高 |
