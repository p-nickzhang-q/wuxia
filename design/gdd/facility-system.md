# 门派设施系统 (Facility System)

> **Status**: Designed
> **Author**: User + Claude
> **Last Updated**: 2026-04-29
> **Implements Pillar**: 门派经营基础

## Overview

门派设施系统管理门派建筑的建造和升级。玩家消耗银两建设设施（练武场、藏经阁、炼丹房、议事厅、弟子房），每种设施提供不同功能：练武场提升武功熟练度、藏经阁学习新武功、炼丹房炼制丹药、议事厅接受江湖任务、弟子房增加弟子上限并提供睡觉恢复精力的房间。该系统是门派经营的核心，将银两转化为门派能力提升和弟子管理空间。

## Player Fantasy

设施系统让玩家感受到门派建设的成就感——从一个小门派逐步发展为设施完备的武林大派。每次建设新设施，玩家看到门派规模扩大，感受"我的门派越来越强了"的成长感。弟子房建设让玩家能为弟子提供更好的休息环境，体验作为掌门人对弟子的关怀。设施升级带来的功能增强，让玩家有"值得投资"的决策满足感。

## Detailed Design

### Core Rules

**设施类型与功能**：

| 设施 | 功能 | 基础建设成本 | 升级效果 |
|------|------|-------------|----------|
| 徒手练武场 | 提升空手类武功熟练度 | 200银两 | 训练效率+20%/级 |
| 兵器练武场 | 提升兵器类武功熟练度 | 200银两 | 训练效率+20%/级 |
| 藏经阁 | 学习新武功 | 300银两 | 解锁更高级武功 |
| 炼丹房 | 炼制丹药 | 150银两 | 解锁更高级丹药 |
| 兵器坊 | 制作装备 | 150银两 | 解锁更高级装备 |
| 议事厅 | 接受江湖任务 | 250银两 | 更高奖励任务 |
| 弟子房 | 弟子上限+1，提供房间 | 100银两 | 精力恢复效率+10%/级 |

**设施建设规则**：
1. 可建设多个同类型设施（弟子房可建设多个）
2. 建设消耗银两，检查余额 ≥ 建设成本
3. 建设后设施等级为1（基础等级）
4. 建设即时完成（无等待时间）

**设施升级规则**：
1. 每个设施最多升级到等级5
2. 升级成本 = 基础成本 × 当前等级
3. 升级后功能增强（见升级效果）

**弟子房房间机制**：
- 每个弟子房 = 1个房间 = 1个弟子上限
- 弟子房等级N = 精力恢复效率 = 50% + (N-1)×10%
- 需要建设多个弟子房来容纳多个弟子
- 弟子睡觉时占用自己的房间，睡醒后释放房间

**弟子房等级与精力恢复效率**：

| 弟子房等级 | 精力恢复效率 | 弟子上限贡献 |
|-----------|-------------|-------------|
| 1 | 50% | 1 |
| 2 | 60% | 1 |
| 3 | 70% | 1 |
| 4 | 80% | 1 |
| 5 | 90% | 1 |

**初始门派状态**：
- 开局无设施
- 弟子上限为0（必须先建设弟子房才能招募弟子）
- 初始银两500，可建设1个弟子房（100银两）并招募1个弟子

### States and Transitions

**设施等级状态**：

| 状态 | 说明 |
|------|------|
| 未建设 | 设施不存在 |
| 已建设（等级1） | 设施存在，基础功能 |
| 已升级（等级2-5） | 设施功能增强 |

**弟子房房间状态**：

| 状态 | 说明 |
|------|------|
| 空闲 | 房间可用，弟子可以睡觉 |
| 占用 | 房间被弟子使用，其他弟子不能使用 |

**状态转换**：
- 未建设 → 已建设：消耗银两建设设施
- 已建设 → 已升级：消耗银两升级设施
- 空闲 → 占用：弟子开始睡觉
- 占用 → 空闲：弟子睡醒结束

### Interactions with Other Systems

| 系统 | 方向 | 数据流 | 接口 |
|------|------|--------|------|
| 资源系统 | 消费者 | 银两 | `canAfford(cost): boolean`<br>`deductSilver(cost): boolean` |
| 精力系统 | 恢复者 | 房间状态 | `hasFreeRoom(discipleId): boolean`<br>`getRoomRecoveryRate(discipleId): number`<br>`startSleep(discipleId): void`<br>`endSleep(discipleId): void` |
| 弟子系统 | 容量提供者 | 弟子上限 | `getDiscipleCapacity(): number` |
| 武功学习系统 | 功能提供者 | 训练效率 | `getTrainingEfficiency(facilityType): number` |
| 制作系统 | 功能提供者 | 制作场所 | `hasFacility(facilityType): boolean` |
| 江湖任务系统 | 功能提供者 | 任务场所 | `hasFacility('议事厅'): boolean` |
| 存档系统 | 持久化 | 设施状态 | `getFacilityState(): FacilityState[]`<br>`restoreFacilityState(state: FacilityState[])` |
| UI系统 | 显示 | 设施信息 | `getFacilities(): Facility[]` |

## Formulas

### 升级成本公式

```
升级成本 = 基础成本 × 当前等级

基础成本（各设施）：
- 徒手练武场: 200
- 兵器练武场: 200
- 藏经阁: 300
- 炼丹房: 150
- 兵器坊: 150
- 议事厅: 250
- 弟子房: 100
```

**示例计算**：

| 设施 | 基础成本 | 升级到等级2 | 升级到等级3 | 升级到等级5 |
|------|---------|------------|------------|------------|
| 弟子房 | 100 | 100×1=100 | 100×2=200 | 100×4=400 |
| 藏经阁 | 300 | 300×1=300 | 300×2=600 | 300×4=1200 |
| 徒手练武场 | 200 | 200×1=200 | 200×2=400 | 200×4=800 |

### 训练效率公式

```
训练效率 = 基础效率 × (1 + 设施等级 × 0.2)

基础效率 = 1.0
```

**示例计算**：

| 设施等级 | 训练效率 |
|---------|----------|
| 1 | 1.0 × (1 + 0.2) = 1.2 |
| 3 | 1.0 × (1 + 0.6) = 1.6 |
| 5 | 1.0 × (1 + 1.0) = 2.0 |

### 弟子房精力恢复效率公式

```
精力恢复效率 = 50% + (弟子房等级 - 1) × 10%
```

**示例计算**：

| 弟子房等级 | 精力恢复效率 |
|-----------|-------------|
| 1 | 50% + 0×10% = 50% |
| 2 | 50% + 1×10% = 60% |
| 3 | 50% + 2×10% = 70% |
| 5 | 50% + 4×10% = 90% |

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 银两不足时尝试建设 | 拒绝操作，提示"银两不足" |
| 银两不足时尝试升级 | 拒绝操作，提示"银两不足" |
| 设施已达到最高等级（等级5） | 拒绝升级，提示"设施已达最高等级" |
| 弟子上限已达，尝试招募 | 拒绝招募，提示"弟子房不足，请建设更多弟子房" |
| 弟子睡觉时无空闲房间 | 使用"无房间"恢复公式（20%），耗时更长 |
| 所有房间被占用，新弟子睡觉 | 等待房间空闲或使用"无房间"恢复 |
| 存档恢复时设施等级无效（如等级6） | 恢复为等级5，记录警告 |
| 存档恢复时设施类型无效 | 忽略无效设施，记录警告 |

## Dependencies

### 上游依赖

| 系统 | 依赖类型 | 接口需求 |
|------|---------|----------|
| 弟子系统 | 硬依赖 | 需要弟子上限计算 |
| 资源系统 | 硬依赖 | 需要银两检查和扣除 |
| 精力系统 | 硬依赖 | 需要房间状态和恢复效率 |

### 下游依赖（被依赖）

| 系统 | 依赖类型 | 接口需求 |
|------|---------|----------|
| 武功学习系统 | 硬依赖 | 需要训练效率（徒手/兵器练武场） |
| 制作系统 | 硬依赖 | 需要制作场所（兵器坊、炼丹房） |
| 江湖任务系统 | 硬依赖 | 需要任务场所（议事厅） |
| 弟子事务权重系统 | 硬依赖 | 需要设施存在检查（藏经阁、练武场等），不包含江湖任务 |
| 存档系统 | 硬依赖 | 需要设施状态持久化 |
| UI系统 | 软依赖 | 显示设施信息（UI可独立运行） |

## Tuning Knobs

| Knob | 默认值 | 安全范围 | 影响什么 | 极端设置后果 |
|------|--------|----------|----------|-------------|
| 弟子房基础成本 | 100 | 50-300 | 弟子管理门槛 | 太低：弟子过多<br>太高：无法招募弟子 |
| 藏经阁基础成本 | 300 | 100-500 | 武功学习门槛 | 太低：武功解锁太快<br>太高：武功解锁太慢 |
| 徒手练武场基础成本 | 200 | 50-400 | 空手类武功训练门槛 | 同上 |
| 兵器练武场基础成本 | 200 | 50-400 | 兵器类武功训练门槛 | 同上 |
| 炼丹房基础成本 | 150 | 50-300 | 丹药制作门槛 | 同上 |
| 兵器坊基础成本 | 150 | 50-300 | 装备制作门槛 | 同上 |
| 议事厅基础成本 | 250 | 100-500 | 任务门槛 | 同上 |
| 最高设施等级 | 5 | 3-10 | 升级上限 | 太低：成长受限<br>太高：成长过长 |
| 训练效率增量 | 20%/级 | 10%-50%/级 | 训练速度 | 太低：升级无意义<br>太高：升级太强 |
| 弟子房恢复效率增量 | 10%/级 | 5%-20%/级 | 精力恢复速度 | 太低：升级无意义<br>太高：升级太强 |
| 基础精力恢复效率 | 50% | 30%-70% | 弟子房等级1恢复 | 太低：恢复太慢<br>太高：升级无意义 |

## Acceptance Criteria

| # | 验收条件 | 测试方法 |
|---|---------|----------|
| 1 | 弟子房建设正确扣银两 | 银两500，建设弟子房（100），确认银两=400 |
| 2 | 弟子上限正确计算 | 建设1个弟子房，确认弟子上限=1 |
| 3 | 银两不足时建设被拒绝 | 银两50，尝试建设藏经阁（300），确认被拒绝 |
| 4 | 设施升级正确扣银两 | 弟子房等级1银两400，升级等级2（100），确认银两=300 |
| 5 | 设施等级最高为5 | 弟子房等级5，尝试升级，确认被拒绝"已达最高等级" |
| 6 | 训练效率正确计算 | 徒手练武场等级3，确认训练效率=1.6 |
| 7 | 弟子房恢复效率正确计算 | 弟子房等级3，确认精力恢复效率=70% |
| 8 | 弟子上限已达时招募被拒绝 | 弟子上限=1，已有1弟子，尝试招募，确认被拒绝 |
| 9 | 存档正确保存设施状态 | 建设2个设施后保存加载，确认设施状态一致 |
| 10 | 弟子睡觉占用房间 | 弟子睡觉，确认房间状态变为"占用" |
| 11 | 弟子睡醒释放房间 | 弟子睡醒，确认房间状态变为"空闲" |
| 12 | 无房间时恢复效率降低 | 无空闲房间，弟子睡觉，确认使用20%恢复效率 |
