# 时间系统 (Time System)

> **Status**: Approved
> **Author**: User + Claude
> **Last Updated**: 2026-05-09
> **Implements Pillar**: 门派经营基础

## Overview

时间系统管理门派经营的时间流逝。时间以年月日+时辰格式显示，门派主界面时间自动流逝（20秒=1时辰），其他界面（弟子详情、设施建设、江湖任务等）时间暂停。时间流逝影响弟子事务执行进度、事件触发、设施恢复等。玩家可通过暂停按钮手动暂停时间，方便进行策略配置和资源管理。

## Player Fantasy

时间系统让玩家感受到"江湖岁月流逝"的真实感——看着时辰流转、月份更替，感受门派经营的时光流转。门派主界面时间流逝，玩家有"时间在推进，弟子在成长"的沉浸感；进入其他界面时间暂停，玩家有"可以安心决策"的控制感。暂停按钮让玩家有"掌控时间节奏"的权力感——忙碌时暂停规划，空闲时恢复运行。

## Detailed Design

### Core Rules

**时间格式**：

| 时间单位 | 格式 | 范围 | 说明 |
|---------|------|------|------|
| 年 | "第一年"、"第二年"... | 无上限 | 游戏开始为第一年 |
| 月 | "正月"、"二月"... "腊月" | 12个月 | 传统农历月份名称 |
| 日 | "初一"、"初二"... "三十" | 29-30天 | 小月29天，大月30天 |
| 时辰 | "子时"、"丑时"... "亥时" | 12时辰 | 传统十二时辰 |

**12时辰名称与时段**：

| 时辰 | 对应时段 | 进度条颜色 | 环境描述 |
|------|---------|----------|----------|
| 子时 | 23:00-01:00 | 深蓝色 | 深夜 |
| 丑时 | 01:00-03:00 | 深蓝色 | 深夜 |
| 寅时 | 03:00-05:00 | 浅蓝色 | 黎明 |
| 卯时 | 05:00-07:00 | 金色 | 日出 |
| 辰时 | 07:00-09:00 | 金色 | 早晨 |
| 巳时 | 09:00-11:00 | 金色 | 上午 |
| 午时 | 11:00-13:00 | 红色 | 正午 |
| 未时 | 13:00-15:00 | 金色 | 下午 |
| 申时 | 15:00-17:00 | 金色 | 下午 |
| 酉时 | 17:00-19:00 | 橙色 | 日落 |
| 戌时 | 19:00-21:00 | 紫色 | 傍晚 |
| 亥时 | 21:00-23:00 | 深蓝色 | 夜晚 |

**时间流逝规则**：

1. **门派主界面**：时间自动流逝
   - 流逝速度：20秒（实时）= 1时辰（游戏时间）
   - 一天（12时辰）= 240秒（4分钟）
   - 进度条显示当前时辰流逝进度

2. **其他界面**：时间暂停
   - 弟子详情界面：点击弟子卡片进入时暂停
   - 设施建设界面：点击"建设新设施"进入时暂停
   - 江湖任务界面：点击"江湖任务"进入时暂停
   - 事件对话框：事件触发弹出时暂停
   - 弟子招募界面：招募事件弹出时暂停

3. **手动暂停**：
   - 暂停按钮位置：状态栏右侧
   - 暂停时：时间停止流逝，显示▶播放符号
   - 恢复时：时间继续流逝，显示⏸暂停符号

**月份大小规则**：

| 月份 | 天数 | 说明 |
|------|------|------|
| 正月、三月、五月、七月、八月、十月、腊月 | 30天 | 大月 |
| 二月、四月、六月、九月、十一月 | 29天 | 小月 |

**日期转换规则**：

1. 时辰满12 → 日+1，时辰重置为子时
2. 日满当月天数 → 月+1，日重置为初一
3. 月满12（腊月） → 年+1，月重置为正月

### States and Transitions

**时间流逝状态**：

| 状态 | 说明 | 触发条件 |
|------|------|---------|
| 流逝中 | 时间自动推进 | 门派主界面且未手动暂停 |
| 暂停 | 时间停止流逝 | 进入其他界面或手动暂停 |

**状态转换**：
- 流逝中 → 暂停：进入其他界面、点击暂停按钮、事件触发
- 暂停 → 流逝中：返回门派主界面、点击播放按钮、事件对话框关闭

### Interactions with Other Systems

| 系统 | 方向 | 数据流 | 接口 |
|------|------|--------|------|
| 弟子事务权重系统 | 消费者 | 时辰进度 | 事务执行时长以时辰为单位，时间流逝扣除执行进度 |
| 精力系统 | 消费者 | 时间流逝 | 自然恢复每时辰增加精力上限×5%/24 |
| 设施系统 | 消费者 | 房间占用时间 | 弟子睡觉占用房间时长以时辰计算 |
| 江湖事件系统 | 消费者 | 探索时长 | 江湖探索耗时1.5时辰 |
| 存档系统 | 持久化 | 时间状态 | `saveTime(): TimeState`<br>`loadTime(state: TimeState)` |
| UI系统 | 显示 | 时间界面 | 显示年月日、时辰、进度条、暂停按钮 |

## Formulas

### 时辰流逝速度

```
1时辰 = 20秒（实时）
1天 = 12时辰 = 240秒 = 4分钟
1月 = 约30天 = 约2小时
1年 = 12月 = 约24小时
```

### 弟子事务执行进度

```
执行进度 = 已流逝时辰 / 事务总时长

示例：
- 弟子修炼武功（2时辰）
- 已流逝1.5时辰
- 执行进度 = 1.5 / 2 = 75%
- 剩余0.5时辰完成
```

### 精力自然恢复

```
每时辰恢复量 = 精力上限 × 5% / 24 ≈ 精力上限 × 0.21%

示例：
- 精力上限100
- 每时辰恢复 = 100 × 0.21% = 0.21精力
- 一天恢复 = 100 × 5% = 5精力（睡觉恢复50精力）
```

> 自然恢复非常缓慢，鼓励玩家安排弟子睡觉恢复。

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 跨月边界（30→1） | 大月30天后进入下月初一，小月29天后进入下月初一 |
| 跨年边界（腊月→正月） | 腊月30天后进入下一年正月初一 |
| 时间暂停时弟子事务继续 | 不允许——暂停时所有事务进度停止 |
| 暂停期间手动推进时间 | 不支持——只能等待或恢复时间流逝 |
| 存档恢复时间无效（如第13月） | 恢复为腊月，记录警告 |
| 进度条超过100% | 立即推进到下一时辰，进度条重置 |
| 弟子事务执行中途暂停 | 保留执行进度，恢复后继续执行 |

## Dependencies

### 上游依赖

无上游依赖，时间系统是基础系统。

### 下游依赖（被依赖）

| 系统 | 依赖类型 | 接口需求 |
|------|---------|----------|
| 弟子事务权重系统 | 硬依赖 | 需要时辰流逝扣除事务进度 |
| 精力系统 | 硬依赖 | 需要时间流逝触发自然恢复 |
| 设施系统 | 硬依赖 | 需要时间计算房间占用时长 |
| 江湖事件系统 | 硬依赖 | 需要探索时长计算 |
| 存档系统 | 硬依赖 | 需要时间状态持久化 |
| UI系统 | 硬依赖 | 需要时间显示和暂停按钮 |

## Tuning Knobs

| Knob | 默认值 | 安全范围 | 影响什么 | 极端设置后果 |
|------|--------|----------|----------|-------------|
| 时辰流逝速度 | 20秒 | 10-60秒 | 游戏节奏 | 太快：玩家来不及反应<br>太慢：游戏节奏拖沓 |
| 一天时辰数 | 12 | 6-24 | 时间精细度 | 太少：时间变化不明显<br>太多：时间过于复杂 |
| 大月天数 | 30 | 28-31 | 月份长度 | 无明显影响 |
| 小月天数 | 29 | 28-30 | 月份长度 | 无明显影响 |

## Visual/Audio Requirements

**进度条颜色变化**：
- 子时-丑时：深蓝色（深夜氛围）
- 寅时：浅蓝色（黎明过渡）
- 卯时-巳时：金色（日出/上午）
- 午时：红色（正午）
- 未时-申时：金色（下午）
- 酉时：橙色（日落）
- 戌时：紫色（傍晚）
- 亥时：深蓝色（夜晚）

**暂停按钮状态**：
- 流逝中：⏸ 暂停符号，深色背景
- 暂停：▶ 播放符号，高亮背景

暂无特殊音频需求。

## Acceptance Criteria

| # | 验收条件 | 测试方法 |
|---|---------|----------|
| 1 | 时辰流逝速度正确 | 门派主界面等待20秒，确认时辰推进1个 |
| 2 | 一天等于12时辰 | 从子时开始，等待240秒，确认回到子时 |
| 3 | 跨月边界正确 | 当前腊月三十，等待20秒，确认变为下一年正月初一 |
| 4 | 进入弟子详情时间暂停 | 门派主界面时间流逝中，点击弟子，确认时间停止 |
| 5 | 返回门派主界面时间恢复 | 弟子详情界面点击返回，确认时间继续流逝 |
| 6 | 暂停按钮正确工作 | 点击暂停按钮，确认时间停止，图标变为播放符号 |
| 7 | 播放按钮恢复时间 | 暂停状态点击播放，确认时间继续流逝 |
| 8 | 进度条颜色随时辰变化 | 从子时到午时，确认进度条颜色从深蓝变为红色 |
| 9 | 弟子事务时辰扣除正确 | 弟子修炼（2时辰），流逝1时辰后确认进度50% |
| 10 | 存档保存时间状态 | 第一年三月五日未时存档，加载后确认时间一致 |
| 11 | 事件触发时间暂停 | 探索触发仇杀事件，确认时间暂停 |
| 12 | 事件关闭时间恢复 | 仇杀事件对话框关闭，确认时间恢复流逝 |
