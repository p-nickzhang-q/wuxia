# 精力系统 (Vitality System)

> **Status**: Approved
> **Author**: User + Claude
> **Last Updated**: 2026-04-29
> **Implements Pillar**: 门派经营约束

## Overview

精力系统定义弟子精力的消耗和恢复规则。精力是弟子的核心属性，由弟子基础属性（根骨、定力）决定初始值和上限。弟子进行制作、训练、任务等活动消耗精力，精力耗尽后必须睡觉恢复，睡觉需要房间设施。该系统防止玩家通过无限制作刷钱，形成门派经营的资源循环约束。

## Player Fantasy

精力系统让玩家感受到门派经营的真实感——弟子不是机器，需要休息恢复精力。玩家需要在"让弟子继续工作"和"让弟子休息恢复"之间做出决策，体验作为门派掌门人的管理压力。精力耗尽的弟子强制休息，让玩家有"不能压榨弟子过度"的约束感，同时通过建设更多房间设施提升恢复效率，感受门派基础设施的重要性。

## Detailed Design

### Core Rules

**精力属性**：
- 精力是弟子的属性，存储在弟子数据结构中
- 初始精力 = 基础值 + 根骨加成 + 定力加成（公式见Formulas节）
- 精力上限 = 初始精力（固定，不随等级变化）
- 精力下限 = 0
- 当前精力：实时值，消耗后减少，恢复后增加

**精力消耗规则**：

| 活动 | 消耗精力 | 说明 |
|------|---------|------|
| 修炼武功 | 10 + 武功级别×2 | 在藏经阁学习新武功消耗，级别范围1-5，消耗范围10-20 |
| 制作装备 | 10 + 装备等级×5 | 制作装备消耗，等级越高消耗越多 |
| 制作药品 | 5 + 药品等级×3 | 制作药品消耗，等级越高消耗越多 |
| 武功训练 | 15 | 在练武场训练消耗 |
| 江湖探索 | 20（主城10） | 探索城市消耗，主城精力减半 |
| 江湖任务 | 20 | 议事厅任务消耗（不属于权重系统，玩家手动选择执行） |
| 战斗 | 0 | 战斗不消耗精力（战斗已有MP机制） |

> **注意**：江湖任务不在弟子事务权重系统内，玩家通过专门的江湖任务界面选择任务和弟子执行。

**精力恢复规则**：

| 恢复方式 | 恢复量 | 条件 |
|---------|--------|------|
| 睡觉（有房间） | 上限 × 50% | 需要空闲房间，耗时4小时 |
| 睡觉（无房间） | 上限 × 20% | 无房间，露天休息，耗时6小时 |
| 自然恢复 | 上限 × 5%/小时 | 不睡觉时缓慢恢复 |

**精力耗尽后果**：
- 精力为0时，弟子无法进行任何消耗精力的活动
- 系统自动提示"弟子精力耗尽，需要休息"
- 玩家必须安排弟子睡觉恢复

### States and Transitions

**弟子精力状态**：

| 状态 | 精力范围 | 行为能力 | UI提示 |
|------|---------|----------|--------|
| 充沛 | ≥ 70% 上限 | 可进行所有活动 | 无提示 |
| 正常 | 30%-70% 上限 | 可进行所有活动 | 无提示 |
| 低 | < 30% 上限 | 可进行活动 | 警告"精力即将耗尽" |
| 耗尽 | = 0 | 无法进行消耗精力的活动 | 提示"精力耗尽，需要休息" |

**状态转换**：
- 充沛 → 正常 → 低 → 耗尽：通过消耗精力的活动（制作、训练、任务）
- 耗尽 → 低 → 正常 → 充沛：通过睡觉恢复

### Interactions with Other Systems

| 系统 | 方向 | 数据流 | 接口 |
|------|------|--------|------|
| 弟子系统 | 存储者 | 精力值 | 精力作为DiscipleState的属性 |
| 制作系统 | 消费者 | 精力 | `canAffordVitality(discipleId, cost): boolean`<br>`consumeVitality(discipleId, cost): boolean` |
| 训练系统 | 消费者 | 精力 | 同上 |
| 任务系统 | 消费者 | 精力 | 同上 |
| 门派设施系统 | 恢复者 | 房间状态 | `hasFreeRoom(): boolean`<br>`startSleep(discipleId): void` |
| 资源系统 | 约束 | 无直接数据流 | 精力限制制作数量，防止刷钱 |
| UI系统 | 显示 | 精力值 | `getVitality(discipleId): VitalityState` |
| 存档系统 | 持久化 | 精力状态 | 精力值作为弟子存档的一部分 |

## Formulas

### 精力上限公式

```
精力上限 = 基础精力 + 根骨加成 + 定力加成

基础精力 = 50
根骨加成 = 根骨 × 5
定力加成 = 定力 × 3

根骨范围: 1-10
定力范围: 1-10
```

**示例计算**：

| 根骨 | 定力 | 精力上限 |
|------|------|----------|
| 5 | 5 | 50 + 25 + 15 = 90 |
| 1 | 1 | 50 + 5 + 3 = 58 |
| 10 | 10 | 50 + 50 + 30 = 130 |

### 精力恢复公式

```
睡觉恢复（有房间） = 精力上限 × 50%
睡觉恢复（无房间） = 精力上限 × 20%
自然恢复（每小时） = 精力上限 × 5%
```

**示例计算**（精力上限=90）：

| 恢复方式 | 恢复量 |
|---------|--------|
| 睡觉（有房间） | 90 × 50% = 45 |
| 睡觉（无房间） | 90 × 20% = 18 |
| 自然恢复（1小时） | 90 × 5% = 4.5 |

### 修炼武功精力消耗公式

```
修炼武功消耗 = 基础消耗 + 武功级别加成

基础消耗 = 10
武功级别加成 = 武功级别 × 2

武功级别范围: 1-5
消耗范围: 12-20
```

**示例计算**：

| 武功级别 | 精力消耗 |
|---------|---------|
| 1（入门） | 10 + 1×2 = 12 |
| 3（中级） | 10 + 3×2 = 16 |
| 5（高级） | 10 + 5×2 = 20 |

> 参考 `martial-arts-learning-system.md` 和 `disciple-task-priority-system.md`

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 精力为0时尝试消耗活动 | 拒绝操作，提示"弟子精力耗尽，需要休息" |
| 精力不足时尝试消耗（如精力5，需要10） | 拒绝操作，提示"弟子精力不足" |
| 精力恢复超过上限 | 限制为上限值（不允许超过上限） |
| 精力计算结果为负 | 设置为0 |
| 弟子睡觉时没有空闲房间 | 使用"无房间"恢复公式（20%），耗时更长 |
| 多个弟子同时睡觉，房间不足 | 按顺序排队等待房间空闲 |
| 精力上限计算结果异常（如属性溢出） | 限制为最大值200 |
| 存档恢复时精力为负数 | 恢复为0，记录警告 |

| 系统 | 依赖类型 | 接口需求 |
|------|---------|----------|

| 训练系统 | 硬依赖 | 需要精力检查和消耗接口 |
| 任务系统 | 硬依赖 | 需要精力检查和消耗接口 |

| 存档系统 | 硬依赖 | 精力值作为弟子存档的一部分 |

## Tuning Knobs

| Knob | 默认值 | 安全范围 | 影响什么 | 极端设置后果 |
|------|--------|----------|----------|-------------|
| 基础精力 | 50 | 20-100 | 弟子精力基础值 | 太低：弟子精力太少，频繁休息<br>太高：弟子精力过多，失去约束感 |
| 根骨加成系数 | 5 | 1-10 | 根骨对精力的贡献 | 太低：根骨属性不重要<br>太高：根骨差异过大 |
| 定力加成系数 | 3 | 1-8 | 定力对精力的贡献 | 同上 |
| 精力上限最大值 | 200 | 100-500 | 防止属性溢出 | 太低：高属性弟子受限<br>太高：无意义限制 |
| 制作装备基础消耗 | 10 | 5-20 | 制作装备基础精力成本 | 太低：刷钱漏洞<br>太高：制作太慢 |
| 制作装备等级加成 | 5 | 2-10 | 每级增加精力消耗 | 太低：高级装备太容易<br>太高：高级装备太耗精力 |
| 制作药品基础消耗 | 5 | 2-15 | 制作药品基础精力成本 | 同上 |
| 制作药品等级加成 | 3 | 1-8 | 每级增加精力消耗 | 同上 |
| 训练消耗 | 15 | 5-30 | 训练频率限制 | 太低：训练过快<br>太高：训练太慢 |
| 任务消耗 | 20 | 10-50 | 任务频率限制 | 同上 |
| 睡觉恢复比例（有房间） | 50% | 30%-100% | 房间价值感 | 太低：房间无用<br>太高：恢复太快 |
| 睡觉恢复比例（无房间） | 20% | 10%-50% | 无房间惩罚感 | 太低：无法恢复<br>太高：房间不重要 |
| 自然恢复比例 | 5%/小时 | 1%-10%/小时 | 不睡觉时的恢复速度 | 太低：必须睡觉<br>太高：精力约束失效 |
