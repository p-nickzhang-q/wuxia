# 江湖地图系统 (Jianghu Map System)

> **Status**: Approved
> **Author**: User + Claude
> **Last Updated**: 2026-05-06
> **Implements Pillar**: 江湖世界

## Overview

江湖地图系统管理游戏世界的城市分布和属性。地图包含10个城市（洛阳、长安、开封、杭州、苏州、成都、大理、敦煌、燕京、襄阳），每个城市定义资源等级（木材等级、金属等级、药材等级）、事件类型概率、门派归属。玩家派遣弟子探索城市，消耗精力和时间，触发事件或开采资源。该系统为门派势力系统和江湖事件系统提供基础地图数据，定义资源分布和事件发生地点。

## Player Fantasy

江湖地图系统让玩家感受到"行走江湖"的冒险感——派遣弟子前往不同城市，体验从门派出发探索广阔世界的自由。不同城市的资源等级差异，让玩家有"规划探索路线"的策略感——去高资源等级城市获取更多材料，还是去低等级城市快速探索？每个城市有门派归属，让玩家感受江湖世界的势力格局，与友好门派的城市探索更安全，与敌对门派的城市探索有风险。探索触发随机事件，让玩家有"未知挑战"的期待感——可能是宝藏机遇，也可能是仇杀危机。

## Detailed Design

### Core Rules

**城市列表与属性**：

地图包含10个城市，每个城市定义资源等级、事件类型概率、门派归属：

| 城市 | 门派归属 | 木材等级 | 金属等级 | 药材等级 | 主要事件类型 |
|------|----------|----------|----------|----------|--------------|
| 洛阳 | 少林 | 3 | 2 | 4 | 寻宝事件 |
| 开封 | 丐帮 | 2 | 3 | 2 | 比武事件 |
| 大理 | 大理段氏 | 4 | 2 | 3 | 招募事件 |
| 敦煌 | 天山派 | 2 | 4 | 5 | 仇杀事件 |
| 长安 | 华山 | 3 | 3 | 2 | 比武事件 |
| 燕京 | 武当 | 2 | 2 | 3 | 寻宝事件 |
| 杭州 | 桃花岛 | 4 | 4 | 4 | 寻宝事件 |
| 苏州 | 古墓派 | 3 | 2 | 3 | 招募事件 |
| 襄阳 | 魔教 | 5 | 5 | 3 | 仇杀事件 |
| 成都 | 青城派 | 3 | 2 | 4 | 比武事件 |

**资源等级说明**：
- 资源等级范围：1-5级
- 资源等级决定开采获得量（详见资源系统开采公式）
- 高资源等级城市开采获得更多材料

**事件类型说明**：
- 仇杀事件：遇到仇家或敌人，触发战斗
- 寻宝事件：发现宝藏或秘籍，获得奖励（银两、声望、秘籍碎片）
- 比武事件：遇到比武邀请，参与比试（胜利获得声望）
- 招募事件：遇到可招募的弟子（消耗银两招募）

**门派归属说明**：
- 每个城市归属一个门派（参考CHARACTERS.md中角色的门派）
- 一个门派只有一个城市归属
- 部分门派（少林、峨眉）未分配城市，后续可扩展

**探索流程**：

1. 选择城市：玩家从地图选择目标城市
2. 派遣弟子：选择一个弟子前往探索
3. 消耗资源：消耗精力（固定值）和时间（游戏内时间）
4. 探索结果：
   - 开采资源：根据城市资源等级获得木材/金属/药材
   - 触发事件：根据城市事件类型概率触发随机事件
   - 无事件：探索结束，无特殊结果

**探索消耗**：
- 精力消耗：固定20精力
- 时间消耗：根据城市距离不同，耗时2-6小时（游戏内时间）

**探索结果概率**：
- 开采资源：100%（每次探索必定获得资源）
- 触发事件：30%概率触发事件
- 无事件：70%概率

### States and Transitions

**城市状态**：

| 状态 | 说明 |
|------|------|
| 可探索 | 城市开放，弟子可前往探索 |
| 探索中 | 弟子正在探索该城市 |
| 冷却中 | 城市刚被探索完毕，冷却期间不可再次探索 |

状态转换：
- 可探索 → 探索中：派遣弟子开始探索
- 探索中 → 冷却中：探索完成，进入冷却
- 冷却中 → 可探索：冷却结束，可再次探索

**弟子探索状态**：

| 状态 | 说明 |
|------|------|
| 待命 | 弟子在门派待命 |
| 前往中 | 弟子正在前往城市（消耗时间） |
| 探索中 | 弟子正在城市探索（触发事件或开采资源） |
| 返回中 | 弟子正在返回门派（消耗时间） |
| 待命 | 弟子返回门派待命 |

状态转换：
- 待命 → 前往中：选择城市，弟子出发
- 前往中 → 探索中：到达城市，开始探索
- 探索中 → 返回中：探索完成，弟子返回
- 返回中 → 待命：返回门派，恢复待命

## Formulas

### 开采获得量公式

开采获得量与城市资源等级相关（与资源系统对齐）：

```
开采获得量 = 基础获得量 × 资源等级

木材开采获得量 = 5 × 城市木材等级
金属开采获得量 = 3 × 城市金属等级
药材开采获得量 = 2 × 城市药材等级
```

**示例计算**：

| 城市 | 木材等级 | 金属等级 | 药材等级 | 开采获得量 |
|------|----------|----------|----------|------------|
| 洛阳 | 3 | 2 | 4 | 木材15、金属6、药材8 |
| 襄阳 | 5 | 5 | 3 | 木材25、金属15、药材6 |
| 开封 | 2 | 3 | 2 | 木材10、金属9、药材4 |

### 城市距离公式

城市网状结构使用邻接表定义，相邻城市距离=1：

```
城市邻接关系：
洛阳 → 开封、长安、襄阳
开封 → 洛阳、苏州、杭州
大理 → 成都、敦煌
敦煌 → 大理、长安、燕京
长安 → 洛阳、敦煌、燕京
燕京 → 长安、敦煌、杭州
杭州 → 开封、燕京、苏州
苏州 → 开封、杭州、成都
襄阳 → 洛阳、成都、杭州
成都 → 大理、苏州、襄阳

距离计算：使用最短路径算法
相邻城市距离 = 1
非相邻城市距离 = 最短路径长度
```

**示例距离计算**：

| 起点 | 终点 | 最短路径 | 距离 |
|------|------|----------|------|
| 洛阳 | 开封 | 洛阳→开封 | 1 |
| 洛阳 | 大理 | 洛阳→长安→敦煌→大理 | 3 |
| 洛阳 | 杭州 | 洛阳→开封→杭州 | 2 |
| 开封 | 襄阳 | 开封→洛阳→襄阳 | 2 |
| 杭州 | 成都 | 杭州→苏州→成都 | 2 |

### 探索时间公式

探索时间与城市距离相关：

```
探索时间 = 基础时间 + 距离 × 时间增量

基础时间 = 2小时
时间增量 = 1小时/距离
```

**示例计算**：

| 起点 | 终点 | 距离 | 探索时间 |
|------|------|------|----------|
| 门派 | 洛阳 | 1（假设门派在洛阳附近） | 2+1×1=3小时 |
| 门派 | 大理 | 4 | 2+4×1=6小时 |
| 门派 | 杭州 | 2 | 2+2×1=4小时 |

### 事件触发概率公式

```
事件触发概率 = 基础概率

基础概率 = 30%
无事件概率 = 70%

事件类型概率分布：
仇杀事件 = 25%
寻宝事件 = 30%
比武事件 = 25%
招募事件 = 20%
```

**事件类型与城市对应**：

每个城市有主要事件类型，但可能触发所有类型事件：
- 主要事件类型概率提升（+10%）
- 其他事件类型概率均分剩余概率

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 弟子精力不足时尝试探索 | 拒绝操作，提示"弟子精力不足，无法探索" |
| 城市处于冷却状态时尝试探索 | 拒绝操作，提示"城市冷却中，请等待X小时后再次探索" |
| 弟子已在探索时尝试派遣 | 拒绝操作，提示"弟子已在探索中，无法重复派遣" |
| 探索期间弟子被删除或离开 | 探索自动取消，记录警告 |
| 城市资源等级为0（异常） | 视为资源等级1处理 |
| 城市无门派归属 | 门派归属为"无"，不影响探索功能 |
| 探索结果获得量超过上限 | 限制为该资源类型的合理上限（木材≤50、金属≤30、药材≤20） |
| 事件触发概率异常（如负数） | 设置为默认概率30% |
| 城市邻接表中无连接城市 | 视为孤立城市，无法探索，记录警告 |
| 最短路径计算无法到达目标城市 | 提示"该城市无法到达"，探索被拒绝 |
| 存档恢复时城市状态异常 | 恢复为默认状态（可探索），记录警告 |
| 门派势力关系为敌对时探索敌对城市 | 事件触发概率提升（仇杀事件概率+20%），提示"探索敌对城市风险更高" |

## Tuning Knobs

| Knob | 默认值 | 安全范围 | 影响什么 | 极端设置后果 |
|------|--------|----------|----------|-------------|
| 城市数量 | 10 | 5-20 | 地图规模 | 太少：探索选择有限<br>太多：复杂度过高 |
| 城市资源等级范围 | 1-5 | 1-10 | 资源获得量差异 | 太低：城市差异不明显<br>太高：高级城市过于珍贵 |
| 探索精力消耗 | 20 | 10-50 | 探索频率限制 | 太低：探索过于频繁<br>太高：探索动力不足 |
| 基础探索时间 | 2小时 | 1-4小时 | 探索基础耗时 | 太低：探索过快<br>太高：探索过慢 |
| 时间增量 | 1小时/距离 | 0.5-2小时 | 距离对时间的影响 | 太低：距离不重要<br>太高：远距离城市无吸引力 |
| 事件触发基础概率 | 30% | 10%-50% | 事件触发频率 | 太低：探索乏味<br>太高：事件过频 |
| 仇杀事件概率 | 25% | 10%-40% | 战斗事件频率 | 太低：战斗体验少<br>太高：探索风险过高 |
| 寻宝事件概率 | 30% | 20%-50% | 奖励事件频率 | 太低：奖励感不足<br>太高：奖励过多 |
| 比武事件概率 | 25% | 10%-40% | 比武事件频率 | 同仇杀事件 |
| 招募事件概率 | 20% | 10%-30% | 招募事件频率 | 太低：招募机会少<br>太高：弟子过多 |
| 主要事件类型概率加成 | +10% | 0%-20% | 城市特色突出程度 | 太低：城市无特色<br>太高：其他事件概率过低 |
| 城市冷却时间 | 0小时（无冷却） | 0-24小时 | 城市重复探索限制 | 设置冷却后：城市探索节奏变慢 |
| 城市邻接数量 | 3-4 | 2-6 | 网状结构连通度 | 太少：部分城市孤立<br>太多：距离计算复杂 |
