# 江湖事件系统 (Jianghu Event System)

> **Status**: Approved
> **Author**: User + Claude
> **Last Updated**: 2026-05-06
> **Implements Pillar**: 江湖世界

## Overview

江湖事件系统管理探索城市时触发的随机事件。玩家探索城市时有30%基础概率触发事件，事件分为四种类型：仇杀事件（遇到仇家敌人触发战斗）、寻宝事件（发现宝藏秘籍获得奖励）、比武事件（遇到比武邀请参与比试）、招募事件（遇到可招募弟子）。事件触发概率受门派关系影响，友好门派城市仇杀概率降低，敌对门派城市仇杀概率提升。玩家根据事件类型做出选择，获得奖励（银两、声望、秘籍碎片、弟子）或面临挑战（战斗消耗）。该系统为探索增加随机性和趣味性，让每次探索都有不同的体验，奖励或挑战取决于门派关系。

## Player Fantasy

江湖事件系统让玩家感受到"江湖际遇"的惊喜感——探索城市时可能遇到仇家仇杀，也可能发现宝藏机遇，每次探索都有"未知会发生什么"的期待感。仇杀事件让玩家有"江湖恩怨"的刺激感——与敌对门派弟子战斗，胜利获得功绩和战利品，失败损失精力。寻宝事件让玩家有"意外收获"的惊喜感——发现秘籍碎片或银两宝藏，感受"天上掉馅饼"的运气。比武事件让玩家有"切磋武艺"的成就感——与江湖高手比试，胜利获得声望和认可。招募事件让玩家有"扩充势力"的满足感——遇到优秀弟子候选人，消耗银两将其纳入门派，壮大势力。事件概率受门派关系影响，让玩家有"选择探索城市"的策略感——探索友好城市更安全，探索敌对城市风险更高但奖励可能更丰厚。

## Detailed Design

### Core Rules

**事件类型与规则**：

| 事件类型 | 说明 | 基础概率 | 触发条件 | 奖励/惩罚 |
|---------|------|---------|---------|----------|
| 仇杀事件 | 遇到仇家或敌人，触发战斗 | 25% | 探索城市随机触发 | 胜利：随机装备或药品<br>失败：损失HP，被迫返回 |
| 寻宝事件 | 发现宝藏或秘籍，获得奖励 | 30% | 探索城市随机触发 | 随机奖励：银两30-100、声望10-30、秘籍碎片1-3个（随机选择一种） |
| 比武事件 | 遇到比武邀请，参与比试 | 25% | 探索城市随机触发 | 胜利：获得20声望<br>失败：损失5声望 |
| 招募事件 | 遇到可招募的弟子 | 20% | 探索城市随机触发 | 消耗100-300银两招募弟子，可选择招募或放弃 |

**事件触发流程**：

1. 探索开始：弟子前往城市探索
2. 开采资源：必定获得木材/金属/药材（根据城市资源等级）
3. 事件触发判断：30%基础概率触发事件
4. 事件类型选择：根据事件概率分配随机选择事件类型
5. 城市主要事件类型加成：若触发的事件与城市主要事件类型相同，概率+10%
6. 门派关系修正：根据门派关系等级修正仇杀和寻宝事件概率
7. 事件执行：显示事件详情，玩家做出选择或自动战斗
8. 事件结算：获得奖励或承受惩罚，更新门派关系值

**事件概率分配**：

基础事件概率分配：
- 仇杀事件：25%
- 寻宝事件：30%
- 比武事件：25%
- 招募事件：20%

城市主要事件类型加成：
- 若触发事件与城市主要事件类型相同 → 该事件概率+10%
- 其他事件概率相应减少（均分剩余概率）

门派关系修正（来自门派势力系统）：
- 友好：仇杀概率-10%，寻宝概率+5%
- 中立：无修正
- 敌对：仇杀概率+20%，寻宝概率-5%

**仇杀事件详细规则**：

1. 触发条件：探索城市时随机触发
2. 事件内容：弟子遇到敌对门派的弟子，触发战斗
3. 战斗规则：
   - 弟子与敌对门派弟子进行战斗（简化战斗，不使用完整卡牌系统）
   - 战斗消耗弟子精力10点
   - 战斗结果：胜利或失败
4. 胜利奖励：
   - 获得随机装备或药品（等级1-3级，与城市资源等级相关）
   - 获得功绩15点
   - 门派关系值-15（与敌对门派关系恶化）
5. 失败惩罚：
   - 弟子损失HP（损失的HP = 弟子当前HP的20%）
   - 弟子被迫返回门派
   - 无功绩奖励

**寻宝事件详细规则**：

1. 触发条件：探索城市时随机触发
2. 事件内容：弟子发现宝藏或秘籍，获得奖励
3. 奖励类型（随机选择一种）：
   - 银两奖励：随机30-100银两
   - 声望奖励：随机10-30声望
   - 秘籍碎片：随机1-3个秘籍碎片（用于武功解锁）
4. 无战斗消耗，直接获得奖励
5. 门派关系值不变（寻宝不影响门派关系）

**比武事件详细规则**：

1. 触发条件：探索城市时随机触发
2. 事件内容：弟子遇到江湖高手的比武邀请，参与比试
3. 战斗规则：
   - 弟子与江湖高手比武（简化战斗，不使用完整卡牌系统）
   - 战斗消耗弟子精力10点
   - 战斗结果：胜利或失败
4. 胜利奖励：
   - 获得20声望
   - 获得功绩10点
5. 失败惩罚：
   - 损失5声望
   - 无功绩奖励

**招募事件详细规则**：

1. 触发条件：探索城市时随机触发
2. 事件内容：弟子遇到可招募的弟子候选人，玩家选择招募或放弃
3. 候选人信息：
   - 显示弟子属性（根骨、悟性、定力、臂力、身法，随机1-10）
   - 显示招募费用（100-300银两，与属性相关）
4. 玩家选择：
   - 招募：扣除银两，弟子加入门派
   - 放弃：无消耗，无弟子加入
5. 招募费用公式：
   - 招募费用 = 100 + Σ(属性值) × 10
   - 属性范围：每个属性1-10，总和5-50
   - 招募费用范围：150-600银两（简化为100-300银两）

**门派战争事件详细规则**：

1. 触发条件：玩家与某门派关系达到极敌对（-90以下），且该门派有城市
2. 事件内容：门派战争爆发，玩家选择立场参与
3. 立场选择：
   - 支持友好门派：与敌对门派关系-30，与友好门派关系+30
   - 支持敌对门派：与敌对门派关系+30，与友好门派关系-30
   - 中立旁观：无关系变化，无奖励
4. 奖励：
   - 参与战争且胜利：获得50声望、100银两
   - 参与战争且失败：损失20声望

### States and Transitions

**事件触发状态**：

| 状态 | 说明 | 可转换到 |
|------|------|----------|
| 未触发 | 探索未触发事件 | 已触发 |
| 已触发 | 事件已触发，等待玩家响应 | 已响应 |
| 已响应 | 玩家已做出选择或战斗结束 | 已结算 |
| 已结算 | 事件结算完成，奖励/惩罚已生效 | — |

状态转换：
- 未触发 → 已触发：探索城市时30%概率触发
- 已触发 → 已响应：玩家做出选择（招募/放弃）或战斗结束
- 已响应 → 已结算：奖励或惩罚生效，关系值更新

**战斗事件状态**：

| 状态 | 说明 | 可转换到 |
|------|------|----------|
| 战斗前 | 事件触发，准备战斗 | 战斗中 |
| 战斗中 | 弟子与敌人战斗 | 战斗结束 |
| 战斗结束 | 战斗完成，显示结果 | 事件结算 |

状态转换：
- 战斗前 → 战斗中：开始战斗
- 战斗中 → 战斗结束：战斗胜利或失败
- 战斗结束 → 事件结算：结算奖励或惩罚

## Formulas

### 事件触发概率公式

```
事件触发概率 = 基础概率 + 城市类型加成 + 门派关系修正

基础概率 = 30%（探索城市触发事件的概率）

城市类型加成：
  若触发事件与城市主要事件类型相同 → 该事件概率+10%
  
门派关系修正：
  友好：仇杀概率-10%，寻宝概率+5%
  中立：无修正
  敌对：仇杀概率+20%，寻宝概率-5%
```

**示例计算**：

| 城市 | 门派关系 | 基础概率 | 仇杀概率修正 | 实际仇杀概率 |
|------|---------|---------|-------------|-------------|
| 洛阳（少林，主要事件寻宝） | 友好 | 25% | -10% | 25% - 10% = 15% |
| 襄阳（魔教，主要事件仇杀） | 敌对 | 25% + 10% + 20% | +20% | 25% + 10% + 20% = 55% |
| 大理（大理段氏，主要事件招募） | 友好 | 25% | -10% | 25% - 10% = 15% |

### 事件类型分配概率公式

```
事件类型分配概率：
  仇杀事件：25%（基础）
  寻宝事件：30%（基础）
  比武事件：25%（基础）
  招募事件：20%（基础）

城市主要事件类型加成后概率：
  主要事件类型概率 = 基础概率 + 10%
  其他事件类型概率 = 基础概率 - 均分剩余概率
```

**示例计算**（洛阳，主要事件寻宝）：

| 事件类型 | 基础概率 | 城市加成 | 门派关系修正 | 最终概率 |
|---------|---------|---------|-------------|---------|
| 仇杀 | 25% | -2.5% | -10%（友好） | 12.5% |
| 寻宝 | 30% | +10% | +5%（友好） | 45% |
| 比武 | 25% | -2.5% | 0% | 22.5% |
| 招募 | 20% | -2.5% | 0% | 17.5% |

### 寻宝奖励公式

```
寻宝奖励随机选择一种：

银两奖励 = 随机值(30-100)
  公式：银两 = 30 + random() × 70

声望奖励 = 随机值(10-30)
  公式：声望 = 10 + random() × 20

秘籍碎片奖励 = 随机值(1-3)
  公式：碎片 = 1 + floor(random() × 3)
```

**示例计算**：

| 随机值 | 银两奖励 | 声望奖励 | 秘籍碎片 |
|--------|----------|----------|----------|
| 0.0 | 30 | 10 | 1 |
| 0.5 | 65 | 20 | 2 |
| 1.0 | 100 | 30 | 3 |

### 招募费用公式

```
招募费用 = 基础费用 + 属性加成

基础费用 = 100
属性加成 = Σ(属性值) × 等级系数

简化公式：
招募费用 = 随机值(100-300)
  公式：费用 = 100 + floor(random() × 200)
```

**示例计算**：

| 随机值 | 招募费用 |
|--------|----------|
| 0.0 | 100 |
| 0.5 | 200 |
| 1.0 | 300 |

### 仇杀战斗失败惩罚公式

```
HP损失 = 弟子当前HP × 损失比例

损失比例 = 20%

公式：损失HP = 弟子当前HP × 0.2
```

**示例计算**：

| 弟子当前HP | 损失比例 | 损失HP |
|-----------|---------|--------|
| 100 | 20% | 20 |
| 50 | 20% | 10 |
| 80 | 20% | 16 |

### 随机装备/药品等级公式

```
随机等级 = 城市资源等级 × 随机系数

城市资源等级范围：1-5
随机系数：random() ∈ [0.6, 1.0]

公式：装备/药品等级 = ceil(城市资源等级 × 随机系数)
```

**示例计算**：

| 城市资源等级 | 随机系数 | 装备/药品等级 |
|-------------|---------|--------------|
| 5 | 0.6 | ceil(5 × 0.6) = 3 |
| 5 | 1.0 | ceil(5 × 1.0) = 5 |
| 3 | 0.8 | ceil(3 × 0.8) = 3 |

### 门派战争事件触发条件公式

```
门派战争触发条件：
  玩家与某门派关系值 ≤ -90（极敌对）
  且该门派有城市归属
  
触发概率 = 10%（每次探索极敌对城市时）
```

**示例判断**：

| 玩家与魔教关系值 | 魔教城市归属 | 门派战争触发 |
|------------------------------|-------------|
| -95 | 襄阳 | 可触发（10%概率） |
| -80 | 襄阳 | 不触发（关系值未达极敌对） |
| -100 | 无城市 | 不触发（无城市归属） |

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 事件触发概率超过100% | 限制为100%，即必定触发事件 |
| 事件触发概率低于0% | 限制为0%，即不触发事件 |
| 仇杀战斗失败后弟子HP为0 | 弟子HP设置为1（避免死亡），被迫返回门派 |
| 寻宝奖励随机值超出范围 | 限制在范围内（银两≤100，声望≤30，碎片≤3） |
| 招募事件弟子属性全为1 | 招募费用最低100银两，允许招募低属性弟子 |
| 招募事件弟子属性全为10 | 招募费用最高300银两，允许招募高属性弟子 |
| 玩家银两不足以招募弟子 | 提示"银两不足"，无法招募，可选择放弃 |
| 弟子精力不足时触发战斗事件 | 提示"弟子精力不足"，事件自动取消，探索继续 |
| 门派战争事件同时满足多个门派条件 | 优先触发关系值最低的门派战争 |
| 门派战争事件玩家选择中立 | 无奖励无惩罚，关系值不变 |
| 存档恢复时事件记录异常 | 清空事件记录，记录警告 |
| 城市无主要事件类型定义 | 使用默认概率分配（仇杀25%、寻宝30%、比武25%、招募20%） |
| 城市无门派归属 | 门派关系修正为0%（无修正） |
| 仇杀胜利获得的装备/药品等级为0 | 视为等级1处理 |
| 招募事件弟子候选人与已有弟子重复 | 允许招募重复属性的弟子（弟子ID不同） |
| 比武事件失败后声望为负数 | 声望限制为0，不允许负数 |
| 门派战争事件触发后关系值超出范围 | 限制在-100~100范围内 |
| 事件触发时弟子正在其他城市探索 | 事件排队等待，当前探索完成后触发 |
| 事件结算时弟子已被删除 | 事件自动取消，无奖励无惩罚 |
| 寻宝获得秘籍碎片时武功解锁系统未实现 | 暂存秘籍碎片，等待武功解锁系统实现后使用 |

## Tuning Knobs
