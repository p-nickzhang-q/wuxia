## 1. 概述

### 1.1 游戏简介

武侠卡牌对战游戏是一款回合制卡牌对战游戏，核心机制为**基于轻功的行动顺序系统**。玩家扮演武侠角色，使用卡牌和武功招式与对手战斗，直到击败对方。

### 1.2 设计意图（用户澄清）

- **轻功系统**：类似敏捷属性，轻功越高行动越快，甚至可以在一回合内多次行动
- **卡牌类型作为武功媒介**：武侠主题契合，不同武功需要不同武器/招式类型的手牌
- **直接伤害计算**：通过武功招式和内功提供战斗变化，无攻防公式
- **角色差异化**：保持当前设计，以平衡性为主

### 1.3 核心体验目标

1. **策略深度** — 轻功资源管理、手牌选择、武功招式时机
2. **武侠沉浸** — 角色招式、内功设计贴合金庸武侠世界
3. **快节奏对战** — 单局5-10分钟，决策明确

## 2. 核心机制

### 2.1 轻功行动顺序系统（核心创新）

**描述**：轻功值决定回合内行动顺序和次数

**实现逻辑**：
```
1. 回合开始时比较双方轻功值，高者先行动
2. 使用卡牌/招式消耗轻功值（agilityCost）
3. 当当前行动方轻功 ≤ 对方轻功时，切换行动方
4. 轻功高者可能获得多次行动机会
```

**设计意图**：
- 模拟武侠中"轻功高者先发制人"的概念
- 创造资源管理策略：每回合花多少轻功？
- 高轻功角色可以连续行动，形成压制感

**玩家体验**：
- "我的轻功比你高，我可以先出招"
- "我要省点轻功，不然你会抢到行动权"
- "轻功高就是快，能打好几下"

### 2.2 卡牌系统

**卡牌类型**：

| 类型 | 说明 | 代表招式 |
|------|------|----------|
| 空手 | 徒手攻击 | 拳击、掌击、肘击 |
| 短兵 | 剑、刀等短兵器 | 刺击、挥砍、格挡 |
| 长兵 | 枪、棍等长兵器 | 横扫、直刺、架势 |
| 腿法 | 腿部攻击 | 前踢、扫腿、跃击 |

**卡牌属性**：

| 属性 | 说明 |
|------|------|
| baseDamage | 基础伤害值 |
| baseShield | 获得的护盾值 |
| agilityCost | 消耗的轻功值 |
| selfDamage | 自身反伤（可选） |

**牌库流程**：
```
牌组(Deck) → 洗牌 → 抽牌 → 手牌(Hand, 上限7张) → 使用 → 弃牌堆(DiscardPile)
               ↑                                          │
               └──────────────── 弃牌堆用完时洗回 ────────┘
```

**初始设置**：
- 开局：抽5张牌
- 每回合开始：抽2张牌

### 2.3 武功招式系统

**描述**：武功招式是需要特定类型手牌作为媒介的强力技能

**使用条件**：
1. 拥有对应类型的手牌（媒介）
2. MP 足够支付 mpCost
3. 当前轻功足够支付 agilityCost

**招式效果类型**：

| 效果类型 | 说明 | 示例 |
|----------|------|------|
| damage | 造成伤害 | 降龙十八掌：造成10点伤害 |
| damage + ignoreShield | 无视护盾伤害 | 六脉神剑：造成12点伤害，无视护盾 |
| shield | 获得护盾 | 太极拳：获得4点护盾 |
| selfDamage | 自身受伤 | 七伤拳：自身失去2点体力 |
| drainMp | 吸取内力 | 吸取对方MP并恢复自身MP |
| removeMp | 化解内力 | 消除对方MP并造成等量伤害 |
| drainHp | 吸取生命 | 吸血类武功 |
| dot | 持续伤害 | 生死符：每回合造成伤害 |
| debuffAgility | 降低轻功 | 兰花拂穴手：对方下回合轻功-3 |
| disableCardType | 封印卡牌类型 | 封印对方某类卡牌 |
| extraAction | 额外行动 | 可再行动一次 |
| followUp | 追击 | 天山折梅手：可追击一次 |
| mimic | 模仿 | 小无相功：模仿上一次使用的武功 |

### 2.4 内功系统（被动技能）

**描述**：内功是自动触发的被动效果，按触发时机激活

**触发时机**：

| 时机 | 说明 | 示例内功 |
|------|------|----------|
| TURN_START | 回合开始 | 九阳神功：回合开始恢复HP |
| TURN_END | 回合结束 | 易筋经：回合结束恢复MP |
| ON_DAMAGE | 造成伤害时 | 北冥神功：造成伤害时吸取MP |
| ON_TAKE_DAMAGE | 受到伤害时 | 北冥真气：有概率闪避并反弹伤害 |
| ON_PLAY_CARD | 使用基础招式时 | 某些内功加成基础招式伤害 |
| ON_SKILL_USE | 使用武功招式时 | 小无相功：减少武功MP消耗 |

**内功效果类型**：
- 伤害加成 (bonusDamage)
- 伤害减免 (reducedDamage)
- 完全闪避 (dodged)
- 反弹伤害 (reflectDamage)
- 状态恢复 (HP/MP恢复)

### 2.5 角色系统

**基础属性**：

| 属性 | 说明 | 典型范围 |
|------|------|----------|
| HP | 生命值 | 50-80 |
| MP | 内力值 | 15-30 |
| baseAgility | 基础轻功 | 8-15 |

**角色配置**：
- 可配置多个武功 (martialArts[])
- 每个武功可包含多个招式 + 一个内功
- 自定义牌组构成

**状态效果**：
- **护盾 (Shield)**：吸收伤害，优先于HP扣除
- **Debuff**：减轻功、禁用卡牌类型
- **DoT**：持续伤害（如生死符）

## 3. 战斗流程

### 3.1 游戏阶段

```
SETUP (准备) → SELECTING (选择行动) → ACTING (执行中) → GAME_OVER (结束)
                    ↑                         │
                    └────── 切换行动方 ───────┘
```

### 3.2 回合流程

```
1. 回合开始
   ├── 重置轻功值
   ├── 处理 Debuff（减轻功效果）
   ├── 触发回合开始内功
   └── 双方各抽2张牌

2. 决定行动顺序
   └── 比较双方轻功，高者先行动

3. 行动阶段（循环）
   ├── 选择卡牌/武功招式
   ├── 消耗轻功/MP
   ├── 执行效果
   ├── 检查是否切换行动方
   └── 检查游戏是否结束

4. 回合结束
   ├── 触发回合结束内功
   ├── 处理DoT效果
   └── 进入下一回合
```

## 5. AI 系统

### 5.1 决策逻辑

**行动优先级**：
1. 检查是否可以使用武功招式（斩杀/高MP时优先）
2. 检查是否需要防御（HP<40%且护盾<3时优先防御卡）
3. 选择最高效率攻击卡牌
4. 兜底：使用最低消耗卡牌

**武功使用条件**：
- 玩家HP ≤ 15（斩杀）
- 自身MP ≥ 50%（内力充足）

**防御条件**：
- 自身HP < 40%
- 自身护盾 < 3
- 玩家HP > 50%

### 5.2 卡牌选择策略

**攻击卡选择**：
- 对方有护盾时：选伤害最高的卡
- 对方无护盾时：选伤害/轻功比最高的卡

**防御卡选择**：
- 选护盾值最高的卡，轻功消耗相同时选护盾高的

## 6. 边界情况

### 6.1 已处理

| 情况 | 处理方式 |
|------|----------|
| 牌组用完 | 弃牌堆洗回牌组 |
| 手牌达到上限 | 不再抽牌 |
| 轻功不足 | 无法使用高消耗卡牌 |
| MP不足 | 无法使用武功招式 |
| 目标死亡 | 立即结束游戏 |
| 无可用卡牌 | 跳过行动，结束回合 |

### 6.2 需要注意

| 情况 | 当前状态 | 建议 |
|------|----------|------|
| 同时死亡 | 未明确处理 | 判定为平局或玩家胜利 |
| 无限循环 | 有maxActions=10限制 | 已有保护 |
| 护盾溢出 | 无上限 | 考虑添加护盾上限 |
