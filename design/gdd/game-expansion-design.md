# 武侠霸业 - 扩展设计文档

**创建日期**: 2026-04-02  
**基于**: 现有武侠卡牌对战游戏  
**参考游戏**: 天下霸图、三国杀

## 一、项目愿景

将现有卡牌战斗游戏扩展为完整的武侠门派经营模拟游戏，包含：
- 多人战斗系统（距离机制）
- 弟子养成系统
- 门派经营系统
- 江湖世界系统

## 二、战斗系统扩展

### 2.1 多人战斗模式

#### 模式一：阵营对抗
- 分为两方（如正派 vs 邪派）
- 每方最多 3-5 个角色
- 消灭对方全部角色获胜

#### 模式二：多人混战
- 所有玩家围成圆形
- 自由对战，最后存活者胜利
- 可组队或背叛

### 2.2 圆形距离系统（参考三国杀）

#### 布局示意
```
           角色A
         ↗        ↘
   角色H            角色B
      ↑              ↓
   角色G            角色C
      ↖              ↙
           角色F ← E ← D
```

#### 距离计算规则
- 相邻角色距离为 1
- 隔 1 人距离为 2
- 隔 2 人距离为 3
- 顺时针/逆时针取最短距离

#### 武功攻击范围

| 武功类型 | 攻击范围 | 能打到谁 |
|---------|---------|---------|
| 空手基础招式 | 1 | 左右邻居 |
| 降龙十八掌 | 1 | 左右邻居 |
| 六脉神剑 | 3 | 隔2人以内 |
| 弹指神通 | 2 | 隔1人以内 |
| 打狗棒法 | 2 | 隔1人以内 |
| 独孤九剑 | 1-2 | 邻居或隔1人 |

#### 轻功作用（保持现有机制）

**轻功不改变距离计算**，保持当前战斗作用：
1. **决定行动顺序** - 轻功高者先行动
2. **决定行动次数** - 轻功差距大可获得多次行动
3. **消耗机制** - 使用卡牌/武功消耗轻功值
4. **行动权切换** - 当前行动方轻功 ≤ 对方时切换

### 2.3 目标选择

- 使用武功时需选择合法目标
- 目标必须在武功攻击范围内
- 部分武功可攻击多个目标（如狮子吼）

### 2.4 合击技

特定角色组合同时在场时可触发合击：
| 合击技 | 角色组合 | 效果 |
|-------|---------|------|
| 双剑合璧 | 杨过 + 小龙女 | 高伤害连击 |
| 降龙+打狗 | 乔峰 + 洪七公 | 范围伤害 |

## 三、养成系统：弟子培养

### 3.1 弟子数据结构

```typescript
interface Disciple {
  id: string
  name: string
  
  // 基础属性
  root: number      // 根骨 - 成长潜力
  insight: number   // 悟性 - 学习速度
  will: number      // 定力 - 内功效果
  strength: number  // 臂力 - 伤害加成
  agility: number   // 身法 - 轻功值
  
  // 战斗属性
  maxHp: number
  maxMp: number
  baseAgility: number
  
  // 境界
  realm: '外门' | '内门' | '亲传' | '长老'
  
  // 武功
  learnedSkills: string[]    // 已学会的武功招式
  masteredSkills: string[]   // 已精通的武功招式
  equippedSkills: string[]   // 装备的武功（战斗可用）
  
  // 内功
  passiveSkill: string | null
  
  // 经验
  exp: number
  level: number
}
```

### 3.2 弟子属性说明

| 属性 | 说明 | 影响战斗 |
|------|------|----------|
| 根骨 | 成长潜力 | 属性提升速度 |
| 悟性 | 学习能力 | 武功修炼速度 |
| 定力 | 心性稳定 | 内功效果+X% |
| 臂力 | 力量 | 伤害加成 |
| 身法 | 敏捷 | 基础轻功值 |

### 3.3 境界系统

```
外门弟子 → 内门弟子 → 亲传弟子 → 长老
```

| 境界 | 弟子上限 | 武功槽位 | 特权 |
|------|---------|---------|------|
| 外门 | - | 1 | 基础武功 |
| 内门 | - | 2 | 进阶武功 |
| 亲传 | - | 3 | 秘传武功 |
| 长老 | - | 4 | 镇派武功 |

### 3.4 武功修炼

- 弟子在藏经阁学习武功
- 悟性越高，修炼越快
- 精通后武功效果提升

## 四、门派经营系统

### 4.1 门派设施

| 设施 | 功能 | 升级效果 |
|------|------|---------|
| 练武场 | 提升基础属性 | 更高属性上限 |
| 藏经阁 | 学习新武功 | 解锁更多武功 |
| 炼丹房 | 炼制丹药 | 更高级丹药 |
| 议事厅 | 接受江湖任务 | 更高奖励任务 |
| 弟子房 | 增加弟子上限 | 更多名额 |
| 静心堂 | 恢复体力内力 | 更快恢复 |

### 4.2 资源系统

| 资源 | 获取方式 | 用途 |
|------|---------|------|
| 银两 | 任务、战斗 | 建设设施、招募弟子 |
| 声望 | 任务、战斗 | 解锁高级武功 |
| 秘籍碎片 | 战斗掉落 | 合成武功秘籍 |
| 灵材 | 探索、任务 | 炼制丹药 |

### 4.3 弟子招募

- 江湖游历遇到可招募弟子
- 声望越高，遇到优秀弟子概率越大
- 招募消耗银两

## 五、江湖世界系统

### 5.1 江湖地图

- 多个区域（中原、西域、江南等）
- 每个区域有不同事件和资源
- 探索需要消耗时间

### 5.2 门派势力

- 多个NPC门派
- 门派关系（友好/中立/敌对）
- 门派战争事件

### 5.3 江湖事件

- 随机事件（仇杀、寻宝、比武）
- 选择影响声望和关系
- 特殊事件触发隐藏武功

// 战斗位置（圆形布局）
interface BattlePosition {
  characterId: string
  seatIndex: number      // 座位编号 0-N
  team: 'A' | 'B' | null  // 阵营（混战时为null）
}

// 距离计算
function getDistance(from: number, to: number, totalPlayers: number): number {
  const clockwise = Math.abs(to - from)
  const counterClockwise = totalPlayers - clockwise
  return Math.min(clockwise, counterClockwise)
}

// 武功新增攻击范围属性

## 八、设计原则

1. **保留现有战斗核心** - 轻功系统、卡牌机制不变
2. **渐进式扩展** - 每个Phase可独立运行
3. **模块化设计** - 各系统低耦合
4. **数据驱动** - 配置分离，便于调整平衡
