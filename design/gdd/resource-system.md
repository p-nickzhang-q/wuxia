# 资源系统 (Resource System)

> **Status**: Designed
> **Author**: User + Claude
> **Last Updated**: 2026-04-29
> **Implements Pillar**: 门派经营基础

## Overview

资源系统管理玩家的门派财富积累和制作材料。玩家通过战斗胜利和完成江湖任务获得银两和声望，通过采集/购买获得木材、金属、药材。银两用于弟子招募、境界突破、设施建设，声望用于解锁高级武功秘籍，木材用于建造建筑和制作装备，金属用于制作装备，药材用于制作药品。该系统是门派经营的经济基础，为所有养成和建设行为提供资源约束。

## Player Fantasy

玩家扮演门派掌门人，通过积累银两感受到门派从贫寒到富足的成长，通过提升声望感受到在江湖中地位的攀升。资源系统应让玩家在每次消费前有"这笔钱值得花吗"的决策感，在积累到足够资源时有"终于可以解锁/招募了"的成就感。系统不应过于复杂，避免让玩家陷入繁琐的资源管理。

## Detailed Design

### Core Rules

**银两 (Silver)**：
- 初始值：500银两（让玩家能招募第一个弟子）
- 上限：无上限（避免玩家达到上限后失去动力）
- 下限：0（不允许负值）
- 获取：
  - 战斗胜利奖励
  - 江湖任务奖励
  - 制作装备卖出
  - 制作药品卖出
- 消耗：
  - 弟子招募
  - 境界突破（外门500、内门1000、亲传2000）
  - 设施建设

**声望 (Reputation)**：
- 初始值：0声望
- 上限：无上限
- 下限：0
- 获取：
  - 战斗胜利
  - 江湖任务
  - 特殊事件
- 消耗：
  - 解锁高级武功秘籍

**木材 (Wood)**：
- 初始值：50木材
- 上限：无上限
- 下限：0
- 获取：
  - 采集（江湖探索）
  - 购买（商店）
  - 江湖任务奖励
- 消耗：
  - 建造建筑
  - 制作装备

**金属 (Metal)**：
- 初始值：30金属
- 上限：无上限
- 下限：0
- 获取：
  - 采集（江湖探索）
  - 购买（商店）
  - 江湖任务奖励
- 消耗：
  - 制作装备

**药材 (Herb)**：
- 初始值：20药材
- 上限：无上限
- 下限：0
- 获取：
  - 采集（江湖探索）
  - 购买（商店）
  - 江湖任务奖励
- 消耗：
  - 制作药品

**通用规则**：
1. 所有资源消费前必须检查余额 ≥ 消耗量
2. 余额不足时消费操作被拒绝，返回错误提示
3. 资源变化时立即更新UI显示
4. 资源变化需记录来源（用于审计和成就触发）

### States and Transitions

资源系统本身是无状态的数值存储，但资源变化有明确的触发时机：

| 触发时机 | 操作 | 影响资源 |
|---------|------|----------|
| 战斗胜利结束 | 增加奖励 | 银两+、声望+ |
| 任务完成 | 增加奖励 | 银两+、声望+、木材+、金属+、药材+ |
| 弟子招募确认 | 扣除费用 | 银两- |
| 境界突破确认 | 扣除费用 | 银两- |
| 设施建设确认 | 扣除费用 | 银两-、木材- |
| 武功解锁确认 | 扣除费用 | 声望- |
| 装备卖出确认 | 增加收入 | 银两+ |
| 药品卖出确认 | 增加收入 | 银两+ |
| 装备制作确认 | 扣除成本 | 银两-、木材-、金属- |
| 药品制作确认 | 扣除成本 | 银两-、药材- |
| 江湖探索采集 | 增加材料 | 木材+、金属+、药材+ |

## Formulas

### 战斗奖励公式

```
银两奖励 = 基础银两 × 对手难度系数 × 胜利质量系数
声望奖励 = 基础声望 × 对手声望等级

基础银两奖励 = 50
难度系数 = 对手平均HP / 60 (范围 0.8-2.0)
胜利质量系数 = (玩家剩余HP / 玩家最大HP) × 1.5 (范围 0.3-1.5)

基础声望奖励 = 10
对手声望等级 = 对手角色的声望等级 (范围 1-5)
```

**示例计算**：
| 对手HP | 玩家剩余HP% | 银两奖励 | 声望奖励(等级3) |
|--------|------------|----------|----------------|
| 60 | 80% | 50 × 1.0 × 1.2 = 60 | 10 × 3 = 30 |
| 80 | 50% | 50 × 1.33 × 0.75 = 50 | 10 × 3 = 30 |
| 48 | 100% | 50 × 0.8 × 1.5 = 60 | 10 × 2 = 20 |

### 物品卖出公式

装备和药品都有等级属性，卖出价格与等级挂钩：

```
装备卖出价格 = 基础价格 × 等级系数
药品卖出价格 = 基础价格 × 等级系数

基础价格(装备) = 20
基础价格(药品) = 10
等级系数 = 0.5 + 等级 × 0.5

等级范围: 1-10
```

**示例计算**：
| 物品类型 | 等级 | 卖出价格 |
|---------|------|----------|
| 装备 | 1级 | 20 × (0.5 + 0.5) = 20 |
| 装备 | 3级 | 20 × (0.5 + 1.5) = 40 |
| 装备 | 5级 | 20 × (0.5 + 2.5) = 60 |
| 药品 | 1级 | 10 × 1.0 = 10 |
| 药品 | 3级 | 10 × 2.0 = 20 |
| 药品 | 5级 | 10 × 3.0 = 30 |

### 资源开采公式

木材、金属、药材可通过开采获取，每个地点有资源等级：

```
开采获得量 = 基础获得量 × 资源等级系数

基础获得量(木材) = 5
基础获得量(金属) = 3
基础获得量(药材) = 2

资源等级系数 = 资源等级 × 1.0
资源等级范围: 1-5
```

**示例计算**：
| 资源类型 | 资源等级 | 开采获得量 |
|---------|----------|------------|
| 木材 | 1级 | 5 × 1 = 5 |
| 木材 | 3级 | 5 × 3 = 15 |
| 木材 | 5级 | 5 × 5 = 25 |
| 金属 | 1级 | 3 × 1 = 3 |
| 金属 | 3级 | 3 × 3 = 9 |
| 金属 | 5级 | 3 × 5 = 15 |
| 药材 | 1级 | 2 × 1 = 2 |
| 药材 | 3级 | 2 × 3 = 6 |
| 药材 | 5级 | 2 × 5 = 10 |

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 银两为0时尝试消费 | 拒绝操作，提示"银两不足" |
| 声望为0时尝试消费 | 拒绝操作，提示"声望不足" |
| 木材为0时尝试制作装备 | 拒绝操作，提示"木材不足" |
| 金属为0时尝试制作装备 | 拒绝操作，提示"金属不足" |
| 药材为0时尝试制作药品 | 拒绝操作，提示"药材不足" |
| 奖励计算结果为负 | 设置为0（避免负数） |
| 奖励计算结果超过整数上限 | 限制为 Number.MAX_SAFE_INTEGER 的 1/10 |
| 同时扣除多种资源 | 先检查所有资源是否都足够，全部足够才执行扣除 |
| 卖出等级为0的物品 | 视为等级1处理 |
| 卖出等级超过10的物品 | 视为等级10处理 |
| 资源变化触发多次UI更新 | 使用事件系统，UI订阅变化事件，避免重复更新 |
| 存档恢复时资源为负数 | 恢复为0，记录警告 |
| 开采时资源等级为0 | 视为资源等级1处理 |
| 开采时资源等级超过5 | 视为资源等级5处理 |
| 开采获得量计算结果异常 | 限制为该资源类型基础获得量的10倍 |

### 跨系统约束：精力系统

**防止刷钱漏洞的关键机制**（详见 design/gdd/vitality-system.md）：

制作装备/药品卖出可获得银两利润（卖出价格 > 制作成本），但弟子的精力是有限资源：

```
制作装备/药品 → 消耗银两 + 材料 + 精力 → 卖出获得银两（利润）
精力耗尽 → 必须睡觉恢复 → 需要房间设施 → 需要银两建设
```

**精力系统核心规则**（详见 design/gdd/vitality-system.md）：
- 精力上限 = 基础精力(50) + 根骨×5 + 定力×3
- 制作装备消耗 = 10 + 装备等级×5（与装备等级相关）
- 制作药品消耗 = 5 + 药品等级×3（与药品等级相关）
- 精力耗尽后必须睡觉恢复
- 睡觉恢复精力需要房间设施（有房间恢复50%，无房间恢复20%）
- 房间设施建设消耗银两

**经济平衡含义**：
- 卖出价格可以大于制作银两成本（允许盈利）
- 但精力消耗限制了制作数量，防止无限刷钱
- 高等级装备/药品消耗更多精力，形成等级与成本的平衡
- 房间数量限制了弟子数量和恢复速度，形成资源循环
