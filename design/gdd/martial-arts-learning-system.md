# 武功学习系统 (Martial Arts Learning System)

> **Status**: Approved
> **Author**: User + Claude
> **Last Updated**: 2026-04-30
> **Implements Pillar**: 弟子养成深度

## Overview

武功学习系统管理弟子从学习新武功到精通已学武功的完整修炼流程。玩家主动安排弟子在藏经阁学习新武功（消耗精力和时间），安排弟子在练武场训练已学武功以达到精通（消耗精力和时间）。弟子悟性决定学习速度，境界决定武功槽位上限，藏经阁等级决定可解锁的武功级别。该系统是弟子养成成长的核心，让弟子从只会基础武功成长为掌握多种高级武功的武林高手。

## Player Fantasy

武功学习系统让玩家感受到弟子成长的成就感——看着弟子从只会一招入门武功，逐步学会更高级的武功招式，最终精通多门武功成为武林高手。每次安排弟子学习新武功，玩家有"投资未来"的决策感——选择哪个弟子学习哪门武功。精通武功的过程让玩家有"磨练技艺"的工匠感——不是一蹴而就，而是持续训练才能达到精通。悟性高的弟子学习更快，让玩家在招募时有"慧眼识珠"的满足感。境界提升解锁更多武功槽位，让玩家有"晋升特权"的阶层跃升感。

## Detailed Design

### Core Rules

**武功掌握机制**：

每个武功有经验值（熟练度）百分比，范围 0%~100%。经验值决定武功效果：
- 效果公式：`效果 = 50% + exp × 0.7`
- 0% 经验值 → 50% 效果（刚学会，威力减弱）
- 100% 经验值 → 120% 效果（精通，威力增强）

数据结构：
- `learnedSkills: string[]` - 已学会武功ID列表
- `skillExp: Record<skillId, number>` - 每个武功的经验值百分比

**学习流程**：

1. 学习场所：弟子在藏经阁学习新武功
2. 解锁条件：
   - 藏经阁等级决定可解锁武功级别（等级1解锁级别1武功，等级2解锁级别2武功...）
   - 弟子境界决定武功槽位上限（外门1、内门2、亲传3、长老4、掌门4）
3. 学习消耗：精力（消耗量与武功级别相关），不消耗银两
4. 学习时长：需要等待时间，时长由悟性决定
   - 公式：`学习时长 = 基础时长 / (1 + 悟性 × 0.1)`
5. 学习完成：武功加入 `learnedSkills`，初始经验值为 0%

**训练流程**：

1. 训练场所：弟子在练武场训练已学武功
   - 空手类武功在徒手练武场训练
   - 兵器类武功（短兵、长兵）在兵器练武场训练
2. 训练消耗：每次训练消耗 15 精力
3. 经验值增量：
   - 公式：`增量 = 基础增量 × 悟性系数 × 练武场效率系数`
   - 悟性系数：`1 + 悟性 × 0.1`
   - 练武场效率系数：`1 + 练武场等级 × 0.2`（参考门派设施系统）
4. 经验值上限：上限为 100%，超过时限制为 100%
5. 装备武功：只有已学会的武功才能装备，装备数量受境界槽位限制

### States and Transitions

#### 武功掌握状态

| 状态 | 经验值范围 | 效果范围 | 说明 |
|------|-----------|----------|------|
| 未学会 | - | - | 武功不在 learnedSkills 中 |
| 初学 | 0%-25% | 50%-67.5% | 刚学会，威力减弱 |
| 熟练 | 26%-75% | 67.6%-102.5% | 逐步熟练，效果接近正常 |
| 精通 | 76%-100% | 102.6%-120% | 精通武功，效果增强 |

状态转换：
- 未学会 → 初学：完成学习流程，武功加入 learnedSkills，初始经验值 0%
- 初学 → 熟练：经验值达到 26%
- 熟练 → 精通：经验值达到 76%

#### 弟子修炼活动状态

| 状态 | 说明 | 可转换到 |
|------|------|----------|
| 空闲 | 弟子无修炼活动 | 学习中、训练中 |
| 学习中 | 弟子在藏经阁学习新武功 | 空闲（学习完成或取消） |
| 训练中 | 弟子在练武场训练武功 | 空闲（训练完成或取消） |

状态转换：
- 空闲 → 学习中：安排弟子学习武功（检查精力、境界槽位、藏经阁解锁）
- 学习中 → 空闲：学习时长结束（武功加入 learnedSkills，初始经验值 0%）
- 学习中 → 空闲：取消学习（不消耗精力，武功不加入）
- 空闲 → 训练中：安排弟子训练武功（检查精力 15）
- 训练中 → 空闲：单次训练完成（武功经验值增加）

### Interactions with Other Systems

| 系统 | 方向 | 数据流 | 接口 |
|------|------|--------|------|
| 弟子系统 | 存储者 | learnedSkills, skillExp, 悟性属性 | 弟子数据结构存储武功掌握状态，悟性影响学习和训练速度 |
| 门派设施系统 | 功能提供者 | 藏经阁等级、练武场等级、练武场类型 | `getAvailableSkills(pavilionLevel): string[]`<br>`getTrainingEfficiency(trainingGroundType, trainingGroundLevel): number` |

| 武功招式系统 | 数据源 | 武功定义 | `getSkillData(skillId): MartialArtSkill`（武功级别、类型、效果数值） |

| UI系统 | 显示 | 武功列表、经验值进度 | `getLearnedSkills(discipleId): LearnedSkillInfo[]`

## Formulas

### 武功效果倍率公式

```
效果倍率 = 0.5 + 经验值 × 0.7

经验值范围: 0% - 100%
效果倍率范围: 50% - 120%
```

**示例计算**：

| 经验值 | 效果倍率 | 说明 |
|--------|----------|------|
| 0% | 0.5 + 0 × 0.7 = 50% | 刚学会，威力减半 |
| 25% | 0.5 + 0.25 × 0.7 = 67.5% | 初学阶段 |
| 50% | 0.5 + 0.5 × 0.7 = 85% | 熟练程度 |
| 100% | 0.5 + 1.0 × 0.7 = 120% | 精通，威力增强 |

### 学习时长公式

```
学习时长（秒） = 基础时长 / (1 + 悟性 × 0.1)

基础时长 = 武功级别 × 60秒
武功级别: 1-5（基础到秘传）
悟性范围: 1-10
```

**示例计算**：

| 武功级别 | 基础时长 | 悟性5 | 悟性10 |
|---------|----------|-------|--------|
| 1（基础） | 60秒 | 60 / 1.5 = 40秒 | 60 / 2.0 = 30秒 |
| 3（进阶） | 180秒 | 180 / 1.5 = 120秒 | 180 / 2.0 = 90秒 |
| 5（秘传） | 300秒 | 300 / 1.5 = 200秒 | 300 / 2.0 = 150秒 |

### 学习精力消耗公式

```
学习精力消耗 = 基础精力 + 武功级别 × 级别加成

基础精力 = 5
级别加成 = 5
```

**示例计算**：

| 武功级别 | 精力消耗 |
|---------|----------|
| 1（基础） | 5 + 1 × 5 = 10 |
| 3（进阶） | 5 + 3 × 5 = 20 |
| 5（秘传） | 5 + 5 × 5 = 30 |

### 训练经验值增量公式

```
经验值增量（%） = 基础增量 × 悟性系数 × 练武场效率系数

基础增量 = 5%
悟性系数 = 1 + 悟性 × 0.1
练武场效率系数 = 1 + 练武场等级 × 0.2
```

**示例计算**：

| 悟性 | 练武场等级 | 经验值增量 |
|------|-----------|-----------|
| 5 | 1 | 5% × 1.5 × 1.2 = 9% |
| 5 | 3 | 5% × 1.5 × 1.6 = 12% |
| 10 | 5 | 5% × 2.0 × 2.0 = 20% |

### 训练到精通所需次数

```
精通所需次数 = 100% / 经验值增量

示例：悟性5，练武场等级1 → 增量9%
精通次数 = 100 / 9 ≈ 12次
精力消耗 = 12 × 15 = 180精力
```

## Edge Cases

| 边界情况 | 处理方式 |
|---------|----------|
| 精力不足时尝试学习武功 | 拒绝操作，提示"弟子精力不足，无法学习" |
| 精力不足时尝试训练武功 | 拒绝操作，提示"弟子精力不足，无法训练" |
| 武功槽位已达上限时尝试学习 | 拒绝操作，提示"武功槽位已达上限，请提升境界" |
| 藏经阁等级不足时尝试学习高级武功 | 拒绝操作，提示"藏经阁等级不足，无法学习此武功" |
| 弟子境界不满足武功要求 | 拒绝操作，提示"弟子境界不足，无法学习此武功" |
| 尝试学习已学会的武功 | 拒绝操作，提示"弟子已学会此武功" |
| 尝试训练未学会的武功 | 拒绝操作，提示"弟子尚未学会此武功" |
| 经验值增量超过100%剩余空间 | 经验值限制为100%，不超出上限 |
| 存档恢复时经验值为负数 | 恢复为0%，记录警告 |
| 存档恢复时经验值超过100% | 恢复为100%，记录警告 |
| 取消学习中状态 | 不消耗精力，武功不加入 learnedSkills |
| 学习中弟子被移除（死亡/离开） | 学习自动取消，不消耗精力 |
| 练武场不存在时尝试训练 | 拒绝操作，提示"门派无练武场，无法训练" |
| 藏经阁不存在时尝试学习 | 拒绝操作，提示"门派无藏经阁，无法学习" |
| 空手类武功尝试在兵器练武场训练 | 拒绝操作，提示"空手类武功需在徒手练武场训练" |
| 兵器类武功尝试在徒手练武场训练 | 拒绝操作，提示"兵器类武功需在兵器练武场训练" |

## Tuning Knobs

| Knob | 默认值 | 安全范围 | 影响什么 | 极端设置后果 |
|------|--------|----------|----------|-------------|
| 基础效果 | 50% | 30%-70% | 刚学会武功的威力 | 太低：武功学会后太弱<br>太高：学会即强大，训练动力减弱 |
| 效果增量系数 | 0.7 | 0.5-1.0 | 经验值对效果的贡献 | 太低：训练回报低<br>太高：精通武功过于强大 |
| 训练基础增量 | 5% | 2%-15% | 每次训练经验值增长 | 太低：精通太慢<br>太高：精通太快 |
| 悟性训练系数 | 0.1 | 0.05-0.2 | 悟性对训练效率的影响 | 太低：悟性不重要<br>太高：悟性差异过大 |
| 练武场效率系数 | 0.2 | 0.1-0.4 | 练武场等级对训练效率的影响 | 太低：升级练武场无意义<br>太高：练武场等级过于重要 |
| 学习基础时长 | 60秒/级 | 30-120秒/级 | 学习武功耗时 | 太低：学习无成本感<br>太高：学习太慢 |
| 悟性学习系数 | 0.1 | 0.05-0.2 | 悟性对学习时长的影响 | 太低：悟性不重要<br>太高：悟性差异过大 |
| 学习基础精力 | 5 | 2-10 | 学习武功基础精力消耗 | 太低：学习无约束<br>太高：学习太耗精力 |
| 学习级别精力加成 | 5 | 2-10 | 武功级别对精力消耗的影响 | 太低：高级武功太容易学<br>太高：高级武功太耗精力 |
| 武功级别范围 | 1-5 | 3-10 | 武功级别上限 | 太低：武功分级太少<br>太高：分级过于复杂 |

## Acceptance Criteria

| # | 验收条件 | 测试方法 |
|---|---------|----------|
| 1 | 学习武功正确消耗精力 | 弟子精力100，学习基础武功（消耗10），确认精力=90 |
| 2 | 学习武功正确加入 learnedSkills | 弟子无武功，学习武功后，确认 learnedSkills 包含该武功ID |
| 3 | 学习武功初始经验值为0% | 学习完成后，确认武功 skillExp = 0% |
| 4 | 学习时长与悟性相关 | 悟性5弟子学习基础武功，确认时长=40秒；悟性10弟子，确认时长=30秒 |
| 5 | 训练武功正确消耗精力 | 弟子精力90，训练武功一次，确认精力=75 |
| 6 | 训练武功正确增加经验值 | 悟性5、练武场等级1，训练一次，确认经验值增量=9% |
| 7 | 经验值达到100%时不再增加 | 武功经验值95%，训练一次（增量10%），确认经验值=100%（不超上限） |
| 8 | 武功效果倍率正确计算 | 武功经验值50%，确认效果倍率=85% |
| 9 | 武功槽位限制正确执行 | 外门弟子已有1武功，尝试学习第2武功，确认被拒绝 |
| 10 | 藏经阁等级限制正确执行 | 藏经阁等级1，尝试学习进阶武功（需要等级2），确认被拒绝 |
| 11 | 精力不足时学习被拒绝 | 弟子精力5，尝试学习基础武功（需要10），确认被拒绝 |
| 12 | 精力不足时训练被拒绝 | 弟子精力10，尝试训练武功（需要15），确认被拒绝 |
| 13 | 已学会武功不能重复学习 | 弟子已学会"降龙十八掌"，尝试再次学习，确认被拒绝 |
| 14 | 未学会武功不能训练 | 弟子未学会"六脉神剑"，尝试训练，确认被拒绝 |
| 15 | 存档正确保存武功状态 | 弟子学会2武功、经验值分别为50%、80%，保存后加载，确认状态一致 |
| 16 | 存档恢复无效经验值时修正 | 存档经验值150%，加载后确认恢复为100%并记录警告 |
